# NIST SP 800-218: Secure Software Development Framework (SSDF) Version 1.1 1.1 - PO.3.2

- Framework Code: NIST-SSDF
- Requirement Title: Follow recommended security practices to deploy, operate, and maintain tools and toolchains.

## Mapping Notes

The fixture verifies one tool-integrity practice by checking that immutable tool bytes match an approved expected SHA-256 before execution. It refuses changed bytes before the changed marker is emitted and executes the approved fixture. This supports only the verification slice of SSDF PO.3.2; tool selection, integration, reproducible builds, maintenance, monitoring, and provenance require separate evidence.
