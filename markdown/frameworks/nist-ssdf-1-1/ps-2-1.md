# NIST SP 800-218: Secure Software Development Framework (SSDF) Version 1.1 1.1 - PS.2.1

- Framework Code: NIST-SSDF
- Requirement Title: Make software integrity verification information available to software acquirers.

## Mapping Notes

This control demonstrates one receiver using a signed evidence statement and exact artifact digest before accepting a handoff. It does not require particular signing products, transparency logging, or make verification information available to all software acquirers. NIST SP 800-218 SSDF PS.2.1 is applicable only where the verified receiver is an acquirer and this process makes its verification information available to that acquirer.
