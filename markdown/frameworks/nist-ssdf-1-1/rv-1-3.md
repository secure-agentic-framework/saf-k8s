# NIST SP 800-218: Secure Software Development Framework (SSDF) Version 1.1 1.1 - RV.1.3

- Framework Code: NIST-SSDF
- Requirement Title: Have a policy that addresses vulnerability disclosure and remediation, and implement the roles, responsibilities, and processes needed to support that policy.

## Mapping Notes

SAF-K8S-1005-019 covers disclosure policy, intake and triage time limits. SAF-K8S-1005-020 covers response ownership, escalation and coordination. SAF-K8S-1005-001 provides incident handling support where that lifecycle is connected to the disclosure and remediation process.
