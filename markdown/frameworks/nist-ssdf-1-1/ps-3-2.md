# NIST SP 800-218: Secure Software Development Framework (SSDF) Version 1.1 1.1 - PS.3.2

- Framework Code: NIST-SSDF
- Requirement Title: Collect, safeguard, maintain, and share provenance data for all components of each software release (e.g., in an SBOM).

## Mapping Notes

NIST SSDF PS.3.2 concerns provenance data for all components of each software release. This control's fixture preserves and verifies one signed provenance statement during a single model-metadata registry transfer. It does not generate or maintain a software release SBOM, enumerate every release component, demonstrate acquirer/operations-team distribution, or update provenance as components change. Other SAF-K8S controls cannot be attributed as evidence from this case.
