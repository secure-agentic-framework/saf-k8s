# NIST SP 800-218: Secure Software Development Framework (SSDF) Version 1.1 1.1 - RV.2.2

- Framework Code: NIST-SSDF
- Requirement Title: Plan and implement risk responses for vulnerabilities.

## Mapping Notes

A documented emergency patch and validation may form the chosen risk response for an affected Kubernetes dependency. Retain the underlying risk decision and response evidence.
