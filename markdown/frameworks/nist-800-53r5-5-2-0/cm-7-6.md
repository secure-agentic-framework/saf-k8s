# NIST SP 800-53 Revision 5 5.2.0 - CM-7(6)

- Framework Code: NIST-800-53R5
- Requirement Title: Confined Environments with Limited Privileges

## Mapping Notes

An approved sandbox runtime and separately verified workload privilege limits can support confined execution for the scoped workloads.
