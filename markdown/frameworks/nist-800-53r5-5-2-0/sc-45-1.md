# NIST SP 800-53 Revision 5 5.2.0 - SC-45(1)

- Framework Code: NIST-800-53R5
- Requirement Title: Synchronization with Authoritative Time Source

## Mapping Notes

Compare node clocks with the approved authoritative reference at the profile-defined frequency and synchronize when the approved time difference is exceeded.
