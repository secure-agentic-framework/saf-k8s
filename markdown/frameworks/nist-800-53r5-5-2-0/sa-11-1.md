- Framework Code: NIST-800-53R5
- Requirement Title: Static Code Analysis

## Mapping Notes

The gate mechanism can block promotion on missing or unsuccessful static-analysis evidence when that evidence is an explicit required check. The fixture does not execute static code analysis, validate scanner output, or prove that a developer documented results.
