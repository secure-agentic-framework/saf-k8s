# NIST SP 800-53 Revision 5 5.2.0 - CM-11(3)

- Framework Code: NIST-800-53R5
- Requirement Title: Automated Enforcement and Monitoring

## Mapping Notes

The case demonstrates automatic admission enforcement for an approved image signature on selected GPU Pods and an audit record for a pre-existing policy violation. This is a narrow implementation contribution to automated enforcement and monitoring; it does not establish organization-wide controls over user-installed software.
