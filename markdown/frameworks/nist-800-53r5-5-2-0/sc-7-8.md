# NIST SP 800-53 Revision 5 5.2.0 - SC-7(8)

- Framework Code: NIST-800-53R5
- Requirement Title: Route Traffic to Authenticated Proxy Servers

## Mapping Notes

The tested owned Service path is handled by Istio sidecar proxies, and the destination proxy records the authenticated peer identity. This supports one authenticated-proxy path; it does not establish that all deployed traffic is routed through authenticated proxies.
