# NIST SP 800-53 Revision 5 5.2.0 - SI-7(9)

- Framework Code: NIST-800-53R5
- Requirement Title: Verify Boot Process

## Mapping Notes

Verify each defined boot stage under the effective firmware trust policy. Record the node profile, verified-boot state, enrolled trust policy and covered stages. Treat measured boot as a separate appraisal path that compares authenticated measurements to approved policy and records the resulting decision. Verify applicable provider profiles and exceptions with deployed evidence.
