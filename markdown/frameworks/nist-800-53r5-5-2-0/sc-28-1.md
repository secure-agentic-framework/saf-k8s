# NIST SP 800-53 Revision 5 5.2.0 - SC-28(1)

- Framework Code: NIST-800-53R5
- Requirement Title: Cryptographic Protection

## Mapping Notes

Whole-media encryption supports confidentiality for governed etcd data and WAL. Apply this relationship where the media also uses cryptographic integrity protection against unauthorized modification. The isolated media fixture verifies confidentiality and recovery.
