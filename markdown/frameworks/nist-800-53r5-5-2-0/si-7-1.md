# NIST SP 800-53 Revision 5 5.2.0 - SI-7(1)

- Framework Code: NIST-800-53R5
- Requirement Title: Integrity Checks

## Mapping Notes

Where the organization defines pre-deployment image signature verification as an integrity-check schedule for the covered images. The fixture performs one check for one digest; it does not demonstrate repeated/periodic checks or post-deployment monitoring.
