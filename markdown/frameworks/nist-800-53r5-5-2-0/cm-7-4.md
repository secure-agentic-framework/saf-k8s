# NIST SP 800-53 Revision 5 5.2.0 - CM-7(4)

- Framework Code: NIST-800-53R5
- Requirement Title: Unauthorized Software -- Deny-by-exception

## Mapping Notes

Only where this verified-identity policy is incorporated into an organization-defined deny-by-exception software policy and applied to every relevant execution path. The fixture checks one signed image and rejects mismatched identity/issuer during verification; it does not define the authorized software inventory or enforce a system-wide unauthorized-software deny policy.
