# NIST SP 800-53 Revision 5 5.2.0 - CM-14

- Framework Code: NIST-800-53R5
- Requirement Title: Signed Components

## Mapping Notes

For designated software components whose installation is governed by this verification path. The case verifies the private keyless signature, records the approved image reference in a scoped immutable object, and shows native Pod admission consuming that reference. The deployment must establish coverage and trustworthy approval issuance.
