# NIST SP 800-53 Revision 5 5.2.0 - SC-34

- Framework Code: NIST-800-53R5
- Requirement Title: Non-modifiable Executable Programs

## Mapping Notes

The read-only root-filesystem setting helps protect executable runtime files from modification in the covered inference workload. The control treats model artifacts as data and does not establish image-build integrity or provenance.
