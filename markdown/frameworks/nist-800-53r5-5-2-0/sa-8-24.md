# NIST SP 800-53 Revision 5 5.2.0 - SA-8(24)

- Framework Code: NIST-800-53R5
- Requirement Title: Secure Failure and Recovery

## Mapping Notes

When the external signature verifier is unavailable, the live Gatekeeper policy denies the previously approved image subject; after the verifier returns, the same subject is admitted again. This is a narrow secure-failure/recovery behavior for the image-verification path, not general system fail-safe and recovery.
