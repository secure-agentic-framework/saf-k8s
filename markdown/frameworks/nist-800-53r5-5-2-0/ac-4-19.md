# NIST SP 800-53 Revision 5 5.2.0 - AC-4(19)

- Framework Code: NIST-800-53R5
- Requirement Title: Validation of Metadata

## Mapping Notes

The native policy validates that selected workload metadata (system ID, registry reference, lifecycle class and profile) agrees with one stored synthetic registry parameter before admission. It does not validate metadata for general information-flow decisions or other API resources and paths.
