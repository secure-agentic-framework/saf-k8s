# NIST SP 800-53 Revision 5 5.2.0 - SI-10

- Framework Code: NIST-800-53R5
- Requirement Title: Information Input Validation

## Mapping Notes

This control contributes a bounded input-validity check for a specific approved JSON schema and maximum request-body size. Its 13-check portable fixture verifies that one schema-invalid benign object and one valid typed request one byte over the configured limit are rejected at both a case-owned gateway and mock model, while one valid in-limit request reaches the local recorder. It does not demonstrate the broader source statement's adversarial detection, sanitization, or injection-prevention mechanisms, and it is not evidence for unrelated data-poisoning pipelines.
