# NIST SP 800-53 Revision 5 5.2.0 - SC-16(3)

- Framework Code: NIST-800-53R5
- Requirement Title: Cryptographic Binding

## Mapping Notes

For image transfers where the organization defines signer identity and digest as security attributes to be cryptographically bound to the OCI image. Cosign binds the signature and Fulcio identity to the exact digest and the verifier checks that binding before use. The fixture covers one image and does not establish other security/privacy attribute policies.
