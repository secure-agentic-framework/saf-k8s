# NIST SP 800-53 Revision 5 5.2.0 - SI-2(4)

- Framework Code: NIST-800-53R5
- Requirement Title: Automated Patch Management Tools

## Mapping Notes

The emergency patch procedure may use an approved deployment tool for components in scope. Preserve evidence that the tool actually performed the scoped update.
