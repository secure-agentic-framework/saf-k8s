# NIST SP 800-53 Revision 5 5.2.0 - SI-10(6)

- Framework Code: NIST-800-53R5
- Requirement Title: Injection Prevention

## Mapping Notes

A deployed WAF can provide supporting prevention for untrusted data injections in the organization-defined information inputs when its active rules inspect and block the relevant input. This control's harmless fixed-header marker demonstrates route attachment and a configured WAF decision only; it does not demonstrate application input validation, parameterized interfaces, output escaping, or prevention of prompt or command injection.
