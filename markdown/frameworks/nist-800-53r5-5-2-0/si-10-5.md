# NIST SP 800-53 Revision 5 5.2.0 - SI-10(5)

- Framework Code: NIST-800-53R5
- Requirement Title: Restrict Inputs to Trusted Sources and Approved Formats

## Mapping Notes

This control contributes enforcement of one declared JSON request schema and body-size limit at the case-owned gateway and mock model. The portable fixture does not authenticate or restrict input sources and does not test any secure data-pipeline ingestion path; any applicability is limited to an organization's approved use of this specific format policy.
