# NIST SP 800-53 Revision 5 5.2.0 - RA-3(1)

- Framework Code: NIST-800-53R5
- Requirement Title: Supply Chain Risk Assessment

## Mapping Notes

NIST SP 800-204D provides actionable strategies for integrating software supply-chain security into DevSecOps CI/CD pipelines. The control's documented lifecycle threat model can contribute the supply-chain portion of RA-3(1); its synthetic provenance-gate evidence alone does not establish an organizational risk assessment.
