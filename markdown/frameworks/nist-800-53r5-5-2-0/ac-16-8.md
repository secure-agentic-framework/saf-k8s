## Mapping Notes

Where the organization defines signer identity and image digest as security attributes and uses this keyless signature mechanism to associate those attributes with the image. The fixture demonstrates identity/digest binding for one OCI artifact; it does not define the organization's attribute policy or assure attribute association for other information.
