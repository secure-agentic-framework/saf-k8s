# NIST SP 800-53 Revision 5 5.2.0 - RA-3(3)

- Framework Code: NIST-800-53R5
- Requirement Title: Dynamic Threat Awareness

## Mapping Notes

This control may contribute a bounded threat-information input to RA-3(3) only when an adopter uses validated current threat information in an actual documented risk assessment and maps the information to the in-scope system inventory. The portable proof tests synthetic bundle pin/expiry and exact mock advisory matching; it does not establish live source trust, coverage, inventory matching, risk-analysis judgments, or risk-assessment updates.
