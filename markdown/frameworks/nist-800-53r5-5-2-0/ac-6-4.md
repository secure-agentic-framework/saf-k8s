# NIST SP 800-53 Revision 5 5.2.0 - AC-6(4)

- Framework Code: NIST-800-53R5
- Requirement Title: Separate Processing Domains

## Mapping Notes

A distinct verified runtime for a designated execution domain can support enforced separation of privileges within that domain.
