# NIST SP 800-53 Revision 5 5.2.0 - SA-10(5)

- Framework Code: NIST-800-53R5
- Requirement Title: Mapping Integrity for Version Control

## Mapping Notes

For one selected development tool, the fixture compares the expected SHA-256 with the immutable tool bytes before execution; altered bytes fail before the tool marker is emitted, while the approved bytes execute. This is a narrow verifier example only. The developer must independently maintain and protect the mapping between current-version master build data and the on-site master copy as SA-10(5) requires.
