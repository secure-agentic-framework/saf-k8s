# NIST SP 800-53 Revision 5 5.2.0 - SA-10(5)

- Framework Code: NIST-800-53R5
- Requirement Title: Mapping Integrity for Version Control

## Mapping Notes

Matching the expected SHA-256 to the immutable local tool copy before execution supports a narrow version-to-copy integrity check. The developer must separately maintain correspondence between current-version master build data and the on-site master copy.
