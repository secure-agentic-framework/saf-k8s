# SAF-K8S-0802-006 - Device plugin socket directory access restriction and unauthorized socket access monitoring

- Domain: D08 - GPU, Accelerator, and Confidential Computing
- Knowledge Area: 8.2 - GPU Driver, Library, and Toolkit Security
- Maturity: Practitioner
- Classification: ai-specific

## Statement

Restrict host access to the kubelet device-plugin directory and socket entries to approved platform components. Deny unapproved workload mounts, enforce host ownership and runtime permissions, and monitor API mount decisions and host events as separate sources.

## Objective

Protect authorized plugin operation while restricting and detecting unapproved workload and host use of the device-plugin directory.

## Rationale

Kubernetes admission can evaluate requested hostPath mounts. Host and container runtime policy determine actual directory traversal and access by local processes. Approved device plugin deployments can require directory access so they can register and serve kubelet operations.

## Scope

Applies to Linux Kubernetes nodes with device plugins and their authorized platform workloads and local processes. Document required mounts, permitted components, host policy, audit sources and exceptions.

## Enforcement

- Primary Enforcement Point: Pod and workload admission, effective node filesystem and execution policy, and independently reviewed API and host telemetry.
- Implementation Surface: Restrict hostPath in tenant workloads and isolate approved device plugin components and deployment identities. Verify actual directory and socket ownership, permissions and runtime confinement on governed hosts. Record denied API declarations separately from host access or socket lifecycle events and verify the appropriate monitoring coverage.
- Owner Primary: Platform Engineering
- Owner Supporting: ML Platform Engineering; Security Engineering
