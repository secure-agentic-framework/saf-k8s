# SAF-K8S-0702-020 - Namespace ResourceQuota enforcement for GPU and AI workloads

- Domain: D07 - Storage, Multi-tenancy, and Resource Governance
- Knowledge Area: 7.2 - Namespace Isolation and Multi-Tenancy
- Maturity: Practitioner
- Classification: ai-specific

## Statement

Namespace ResourceQuota objects must enforce approved ceilings at admission for declared accelerator, CPU, memory and storage resources and for relevant object counts in AI and accelerator-consuming namespaces.

## Objective

Prevent any single namespace from exceeding its approved share of GPU and related cluster resources by enforcing namespace-level ResourceQuota boundaries for AI workloads.

## Rationale

Namespace quota bounds the declared allocations admitted for a single namespace. Protect cluster capacity by governing namespace creation, applying quotas before tenant workloads begin, and monitoring actual device and resource capacity.

## Scope

Applies to AI or accelerator-consuming namespaces where GPU, CPU, memory, storage, and relevant object-count ceilings must be enforced through ResourceQuota. LimitRange defaults remain a separate companion control.

## Enforcement

- Primary Enforcement Point: Namespace ResourceQuota objects enforced by the Kubernetes resource quota admission controller and validated through periodic configuration review.
- Implementation Surface: ResourceQuota requests and limits for CPU and memory, requests.storage for declared persistent-volume storage, and relevant Pod, persistent volume claim and Service counts. Use requests.<extended-resource-name> for device-plugin GPUs and MIG resources using the resource name actually advertised. Select approved scope selectors where applicable and review coverage of new and existing namespaces.
