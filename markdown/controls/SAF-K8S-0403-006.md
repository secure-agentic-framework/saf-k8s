# SAF-K8S-0403-006 - Per-workload credential scoping for AI jobs

- Domain: D04 - Identity, Access, and Secrets Management
- Knowledge Area: 4.3 - Secrets Management
- Maturity: Practitioner
- Classification: ai-specific

## Statement

Give governed AI workloads identities and permissions scoped to their approved resources and actions. Distinguish workloads with different authorization needs, and verify the actual accepting service and each alternate credential path.

## Objective

Limit workload access to approved operations and resource boundaries and preserve attribution for each scoped identity.

## Rationale

Workloads sharing a broad grant inherit the effective breadth of that grant. Kubernetes RBAC governs Kubernetes API operations. External authorization depends on supported provider and service actions, resource selectors and identity mappings. Admission can enforce approved identity declarations and is a separate decision.

## Scope

Applies to governed workload types with distinct documented access needs, including training, inference, evaluation, pipelines and notebooks. Specify the Kubernetes and external API or data-plane authorization boundaries.

## Enforcement

- Primary Enforcement Point: Effective API and service authorization, independently verified workload identity assignments and controlled credential issuance.
- Implementation Surface: Identify each actual workload subject, resource and action and its valid provider controls. Verify selected Kubernetes admission, service identities, actual resource grants and alternate credential paths. Exercise a matrix of allowed actions, denied neighboring resources and separately denied broad operations. Document provider limits and approved exceptions.
- Owner Primary: Platform Engineering
- Owner Supporting: Security Engineering; ML Engineering; Cloud Platform Engineering
