# SAF-K8S-0202-002 - RuntimeClass configuration for workload-appropriate isolation

- Domain: D02 - Node, Runtime, and OS Security
- Knowledge Area: 2.2 - Container Runtime Security
- Maturity: Foundational
- Classification: ai-specific

## Statement

Define and enforce approved RuntimeClass assignments for governed workloads. Verify that each class selects the intended configured handler on eligible nodes. Select a supported sandbox where the workload risk requires one, and separately validate the required runtime, driver and device functions for accelerator workloads.

## Objective

Enable workload-specific runtime isolation by assigning appropriate container runtime sandboxing levels based on workload risk profile, with particular attention to AI/ML workloads requiring GPU access.

## Rationale

RuntimeClass selects a configured CRI handler and can constrain scheduling to eligible nodes. Isolation and device behavior depend on the actual handler, runtime version, node platform and workload settings. Validate those properties using a representative workload and retain evidence of the actual handler selection.

## Scope

Applies to all production clusters running mixed workload types or AI/ML workloads requiring GPU access. Clusters running exclusively trusted first-party workloads with homogeneous isolation requirements may document a single-runtime exception. Managed services must configure available RuntimeClass options or document provider-enforced isolation equivalents.

## Enforcement

- Primary Enforcement Point: RuntimeClass definitions, trusted workload classification, admission policy, node readiness inventory and effective runtime handler configuration.
- Implementation Surface: Verified runtime handlers and approved class assignments, trusted namespace or workload classification, eligible node scheduling and readiness labels, actual Pod-to-CRI runtime evidence, and GPU/runtime compatibility tests where applicable.
- Owner Primary: Platform Engineering
- Owner Supporting: AI/ML Platform; Security Engineering
