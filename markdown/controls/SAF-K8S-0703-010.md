# SAF-K8S-0703-010 - Host-level resource isolation for AI workload nodes

- Domain: D07 - Storage, Multi-tenancy, and Resource Governance
- Knowledge Area: 7.3 - Resource Governance and Priority
- Maturity: Practitioner
- Classification: ai-specific

## Statement

Configure cgroup v2 CPU and memory controls for governed AI workloads. Assign exclusive CPUs or use NUMA-aware allocation where documented workload performance or isolation requirements call for those policies, and verify their effective enforcement.

## Objective

Apply and observe the intended kernel resource limits and CPU or memory placement for governed AI workloads on the node classes where they run.

## Rationale

Node affinity and taints govern placement between nodes. Runtime cgroup controls govern CPU and memory use on each node. When a workload qualifies, kubelet policies can assign exclusive CPUs and coordinate applicable resource-topology hints. Measure shared-cache, memory-bandwidth or interconnect behavior separately where it is material to the workload.

## Scope

Applies to all Kubernetes nodes hosting AI workloads, particularly nodes running both training and inference workloads. Cgroup v2 must be enabled and configured for resource isolation. CPU pinning and NUMA awareness must be configured for workloads with performance-sensitive requirements. Dedicated single-purpose clusters may have simplified configurations with documented justification.

## Enforcement

- Primary Enforcement Point: Node-level cgroup v2, CPU Manager, Memory Manager, and NUMA policy configuration on Kubernetes nodes hosting AI workloads.
- Implementation Surface: Verify the active cgroup v2 CPU and memory controllers and effective workload limits. Use the kubelet CPU Manager static policy for eligible exclusive CPU assignment. Where applicable, verify Memory Manager reservations and Topology Manager resource hints. Observe actual accelerator and interconnect behavior when required by the documented workload objectives.
- Owner Primary: Platform Engineering
- Owner Supporting: ML Engineering; SRE
