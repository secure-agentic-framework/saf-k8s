# SAF-K8S-0908-001 - Inference request limits and query monitoring

- Domain: D09 - AI Workload Security: Training, Serving, and Pipelines
- Knowledge Area: 9.8 - Model Abuse and Extraction Prevention
- Maturity: Advanced
- Classification: ai-specific

## Statement

Apply risk-calibrated per-principal request or resource limits and monitor scoped serving events for covered inference endpoints. Verify actual gateway enforcement and approved detection and response for model confidentiality risks.

## Objective

Limit and observe potentially excessive use of governed inference endpoints while preserving approved operations and supporting investigation.

## Rationale

Serving requests can expose model information through granted behavior. Principal limits and scoped logs support rate control and detection. Their effectiveness depends on the endpoint and identity model, traffic coverage, risk analysis and measured detection quality.

## Scope

Applies to governed endpoints selected by the deployed risk assessment. Define principal identity, operations, budget window, exceptions, distributed behavior, telemetry and alert ownership. See SAF-K8S-0908-002 for response minimization and SAF-K8S-0908-005 for broader abuse monitoring.

## Enforcement

- Primary Enforcement Point: Effective request controls at the actual serving gateway and verified detection at the governed event path.
- Implementation Surface: Exercise legitimate requests within a defined policy window, scoped refusal before prediction, an independently approved principal, policy renewal and appropriate minimized events. Verify actual deployment coverage, thresholds, response, and separate privacy and model safeguards.
- Owner Primary: Security Engineering
- Owner Supporting: ML Platform Engineering; API Platform Engineering
