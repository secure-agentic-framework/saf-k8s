# SAF-K8S-0907-006 - Training dataset access restriction across storage backends

- Domain: D09 - AI Workload Security: Training, Serving, and Pipelines
- Knowledge Area: 9.7 - Feature Store Security and Data Access Controls
- Maturity: Practitioner
- Classification: ai-specific

## Statement

Limit governed training data access through the applicable workload identity, API, claim admission and data authorization mechanisms.

## Objective

Enforce and verify least-privilege training data access across the storage and feature backends in use.

## Rationale

Authorization over PVC API objects and admission of Pod references are different decisions. Both are distinct from data and external service access permissions.

## Scope

Applies to training workloads and their persistent volumes, object storage, and feature store access. Include workload identities, claim references, and effective API and data permissions.

## Enforcement

- Primary Enforcement Point: The actual workload identity and claim admission policy, scoped API permissions and storage-native authorization.
- Implementation Surface: Use scoped API authorization, verify effective claim admission and approved workload identity assignment, and configure native storage and feature access policies. Observe approved and denied reads and mounts in the deployed environment.
- Owner Primary: ML Platform Engineering
- Owner Supporting: Data Engineering; Security Engineering; Platform Engineering
