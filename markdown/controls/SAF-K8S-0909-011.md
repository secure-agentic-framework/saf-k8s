# SAF-K8S-0909-011 - Retrieved context integrity validation and relevance threshold enforcement

- Domain: D09 - AI Workload Security: Training, Serving, and Pipelines
- Knowledge Area: 9.9 - RAG Infrastructure Security
- Maturity: Practitioner
- Classification: ai-specific

## Statement

Before assembling retrieved context, verify approved source and chunk identity, version and integrity. Apply documented relevance and result count limits to eligible results and retain the acceptance and denial evidence.

## Objective

Deliver only authorized, intact and sufficiently relevant retrieved material to the approved context consumer.

## Rationale

Retrieval integrity, relevance and downstream semantic safety require separate observations. The relevance score depends on the selected method and calibration; it does not establish provenance or the behavior of prompt processing.

## Scope

Applies to governed retrieval, reranking and context forwarding routes and their audit records. Include metadata validation, approved references and actual model-context integration.

## Enforcement

- Primary Enforcement Point: The retrieval result gate before the governed context consumer.
- Implementation Surface: Bind retrieved results to trusted metadata and content digests. Measure and calibrate relevance thresholds and count limits against approved results. Verify the actual downstream output and absence of rejected content, with audit records for alternate and ordinary routes.
- Owner Primary: ML Platform Engineering
- Owner Supporting: Security Engineering; Security Operations
