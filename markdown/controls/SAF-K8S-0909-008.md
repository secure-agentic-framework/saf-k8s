# SAF-K8S-0909-008 - Classification-aware chunking and vector collection segregation

- Domain: D09 - AI Workload Security: Training, Serving, and Pipelines
- Knowledge Area: 9.9 - RAG Infrastructure Security
- Maturity: Practitioner
- Classification: ai-specific

## Statement

Derive chunk labels from approved source or section classification before indexing. Preserve the labels and retain provenance when routing vectors into approved collections or equivalent enforced retrieval scopes.

## Objective

Keep each chunk and its vector inside the classifications authorized for indexing and retrieval.

## Rationale

Chunks or overlaps that span incompatible sections can carry higher classification data into other scopes. Both the write path and the read path require enforceable classification rules and observable acceptance and denial evidence.

## Scope

Applies to classification assignment, chunk boundaries and overlap, metadata propagation, collection selection and authorization on deployed retrieval paths. Coordinate separately with source identity and provenance validation.

## Enforcement

- Primary Enforcement Point: Trusted classification input, chunk boundary and storage admission checks, and authorization on actual retrieval.
- Implementation Surface: Use authoritative classification metadata and an approved rule for mixed sections, reject missing labels and wrong destination writes, and verify scoped retrieval for independently authenticated principals. Confirm alternate indexes, caches and update paths preserve the same policy.
- Owner Primary: Data Engineering
- Owner Supporting: Security Engineering; ML Platform Engineering
