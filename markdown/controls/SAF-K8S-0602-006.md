# SAF-K8S-0602-006 - Fail-closed admission enforcement of image signature verification

- Domain: D06 - Supply Chain, Images, and Admission Control
- Knowledge Area: 6.2 - Image Signing and Admission Enforcement
- Maturity: Practitioner
- Classification: baseline

## Statement

Require authorized image signatures for each in-scope Kubernetes workload admission request. Verify each governed image and deny the request when the signature cannot be verified or the required admission webhook is unavailable.

## Objective

Prevent new or changed in-scope workloads from being admitted without verified signatures. Evaluate previously admitted workloads and runtime image integrity separately.

## Rationale

Kubernetes webhook failure policy governs communication errors when a matching registered webhook is called. The verifier must also deny requests when signature lookup or validation cannot complete. Verify that effective webhook registration and matching persist through controller outages, upgrades and restarts.

## Scope

Applies to all production and staging Kubernetes clusters. All namespaces must be covered unless explicitly exempted in a documented policy (e.g., kube-system for provider-managed components). Emergency break-glass procedures must be audited and time-limited.

## Enforcement

- Primary Enforcement Point: Kubernetes validating admission webhook and image verification policy configuration.
- Implementation Surface: Verify effective webhook registration, matching namespaces and API operations, applicable container classes, signature formats and approved signer identities. Probe unsigned and allowed images, dependency errors and webhook transport failure separately. Validate cache behavior, exclusions, restart and upgrade lifecycle, and audit evidence for the deployed configuration.
- Owner Primary: Platform Engineering
- Owner Supporting: Security Engineering; DevSecOps / Release Engineering
