# SAF-K8S-0405-006 - Attribute-based access control for AI artifacts

- Domain: D04 - Identity, Access, and Secrets Management
- Knowledge Area: 4.5 - Identity Abuse Detection and Mitigation
- Maturity: Advanced
- Classification: ai-specific

## Statement

Apply approved subject, object, action and environment attributes at the actual artifact authorization boundary. Verify trusted sources for classification and sensitivity, effective enforcement on governed access paths, and authorized attribute changes.

## Objective

Restrict access to the governed model, data and inference artifacts according to the applicable verified identities and contextual policy.

## Rationale

Artifact admission policies can govern resource declarations and metadata. Actual artifact reads require enforcement at the gate that serves the resource. Reliable decisions depend on attributable subject identity and protected object attributes.

## Scope

Applies to governed repositories, stores, model endpoints and data services. Specify policy actions, provenance for applicable subject and object attributes, and the role of admission and resource-side authorization in each path.

## Enforcement

- Primary Enforcement Point: Real resource-side authorization or an independently verified gate on the actual access path, using approved attributes and accountable policy decisions.
- Implementation Surface: Verify trusted identity and request context, protected classification and sensitivity metadata, applicable allow and deny decisions, approved attribute changes, direct access paths and retention. Evaluate Kubernetes admission labeling and validation as distinct supporting mechanisms.
- Owner Primary: Security Engineering
- Owner Supporting: ML Engineering; Data Governance; Platform Engineering
