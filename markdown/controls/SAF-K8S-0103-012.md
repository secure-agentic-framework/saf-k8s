# SAF-K8S-0103-012 - Cloud controller-manager cloud IAM least-privilege scoping

- Domain: D01 - Control Plane and Cluster Hardening
- Knowledge Area: 1.3 - Controller-Manager, Scheduler, and Cloud Controller Security
- Maturity: Practitioner
- Classification: baseline

## Statement

Limit the effective provider permissions of each applicable cloud controller identity to documented operations of enabled controllers. Scope actions, resources and conditions as supported. Record ownership, unavoidable exceptions and periodic review.

## Objective

Preserve required controller duties while preventing authorization outside their approved provider scope.

## Rationale

Cloud actions and effective policy vary by provider, component and enabled controllers. A storage driver, node identity or managed service controller can own an operation separately. Kubernetes API RBAC and provider authorization apply at distinct boundaries.

## Scope

Applies to governed cloud-controller integrations. Identify the Kubernetes and provider versions, enabled duties, effective provider principal, inherited and direct policy sources, supported conditions, shared or provider-owned boundaries and review cadence.

## Enforcement

- Primary Enforcement Point: Effective provider authorization for the resolved controller identity, with independent evaluation of Kubernetes API grants.
- Implementation Surface: Map each active duty to a supported operation and source policy. Exercise required permissions and denied unrelated operations at applicable scopes. Review permissions contributed by all active sources and record exceptions, restrictions and compensating evidence.
- Owner Primary: Platform Engineering
- Owner Supporting: Cloud Platform Engineering; Security Engineering
