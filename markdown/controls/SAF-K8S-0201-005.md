# SAF-K8S-0201-005 - Kubelet hostname override governance

- Domain: D02 - Node, Runtime, and OS Security
- Knowledge Area: 2.1 - Kubelet and Node Configuration Hardening
- Maturity: Foundational
- Classification: baseline

## Statement

Production Kubernetes clusters must prohibit kubelet --hostname-override by default and document approved exceptions. For any exception, verify the effective registered node name, its uniqueness, the authenticated node identity, and the bootstrap authorization or provider controls that bind that identity to the intended node.

## Objective

Prevent kubelet identity spoofing through hostname override misconfiguration while preserving the ability to use the flag in environments where cloud provider node-naming conventions require it.

## Rationale

The kubelet selects a node name from the hostname, an explicit override, or the applicable provider naming mechanism. Node authorization evaluates authenticated kubelet credentials. It requires the system:nodes group and a system:node:<nodeName> username whose node name matches the registered Node. Review name selection and enrollment separately to prevent collisions and preserve the intended binding.

## Scope

Applies to all production Kubernetes clusters. Covers the kubelet --hostname-override flag in kubelet configuration, systemd unit files, and node provisioning templates. For managed Kubernetes services, verify through provider documentation whether hostname override is used internally and how Node authorization identity binding is maintained.

## Enforcement

- Primary Enforcement Point: Node provisioning pipeline, kubelet configuration management, and periodic configuration audit scans.
- Implementation Surface: Kubelet provisioning templates and effective arguments, registered Node name inventory, approved exception records, and credential enrollment or provider attestations for the intended identity. Verify Node authorization and NodeRestriction where applicable.
- Owner Primary: Platform Engineering
- Owner Supporting: Security Engineering; Cloud Platform Engineering
