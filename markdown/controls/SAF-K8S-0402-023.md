# SAF-K8S-0402-023 - Long-lived workload token exception governance and retirement tracking

- Domain: D04 - Identity, Access, and Secrets Management
- Knowledge Area: 4.2 - Service Accounts and Workload Identity
- Maturity: Foundational
- Classification: baseline

## Statement

Inventory Secret-backed Kubernetes service account tokens and identify separately any approved extended-validity Kubernetes TokenRequest or projection configurations. Retire non-expiring tokens where supported and require exact, time-bounded exceptions and re-review for retained non-expiring or explicitly extended uses.

## Objective

Make retained long-lived Kubernetes credential risks, approval, coverage, and retirement independently verifiable.

## Rationale

Legacy auto-generated and manual token Secrets can share the same object type but have different lifecycle evidence. Projected or directly requested Kubernetes tokens have finite lifetimes that depend on applicable settings and managed compatibility behavior. A credential exchanged with a provider has a separate lifecycle.

## Scope

Applies to Secret-backed Kubernetes service account tokens and defined extended-validity Kubernetes token configurations. Record cluster and provider coverage, actual object and workload identities, observed validity, and uncovered environments, and track cloud credentials under the relevant identity controls.

## Enforcement

- Primary Enforcement Point: Metadata-safe inventory, compatibility and exception review, tracked retirement, and separate effective lifetime verification for time-bound paths.
- Implementation Surface: Classify Secret-backed tokens by ServiceAccount references, type and version-specific lifecycle data. Scope each exception by cluster, namespace and actual workload identity with an owner, approval, reason, review deadline and retirement milestone. Verify effective lifetime and retirement by token class. Retain coverage and unknowns without saving token values.
- Owner Primary: Platform Engineering
- Owner Supporting: Security Engineering; Application Development
