# SAF-K8S-0202-009 - Container runtime secure baseline settings and debug endpoint disablement

- Domain: D02 - Node, Runtime, and OS Security
- Knowledge Area: 2.2 - Container Runtime Security
- Maturity: Foundational
- Classification: baseline

## Statement

Maintain version-specific secure runtime profiles with explicit supported CRI and diagnostic interfaces. Disable unneeded diagnostics or restrict approved exceptions, and verify effective listeners and retained workload operation.

## Objective

Constrain the runtime's exposed interfaces while preserving its required Kubernetes CRI services.

## Rationale

A runtime configuration schema, CRI protocol, diagnostics and metrics are distinct. Runtime defaults and effective address settings vary by implementation, version, service and imported configuration.

## Scope

Applies to governed production container runtimes and applicable managed-node responsibility. Inventory version, runtime config and imports, service and socket units, local and network listeners, exceptions and supporting provider evidence.

## Enforcement

- Primary Enforcement Point: Effective runtime and service configuration, actual listeners and exercised required CRI behavior.
- Implementation Surface: Verify supported CRI protocol, approved runtime options, active diagnostic and metrics endpoints and relevant access controls. Exercise available diagnostics only as authorized, verify unneeded listeners absent, and prove a new workload starts with the reviewed effective configuration.
- Owner Primary: Platform Engineering
- Owner Supporting: Security Engineering; OS/Infrastructure
