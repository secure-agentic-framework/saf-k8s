# SAF-K8S-0302-002 - Linux capability drop-all and least-privilege add-back

- Domain: D03 - Workload and Pod Security
- Knowledge Area: 3.2 - Security Contexts and Capabilities
- Maturity: Foundational
- Classification: baseline

## Statement

Require every Linux container to drop ALL capabilities and request only workload-approved additions. For accelerator workloads, verify the minimum effective capability set, successful device use and available least-privilege alternatives before approving an exception.

## Objective

Constrain the privileges available to workload processes while preserving their approved operations.

## Rationale

Linux capabilities are process credentials. Defaults and effective capabilities vary with the runtime, process identity and executable. Admission approves the requested configuration. Verify the effective capabilities and required operations at runtime. A device plugin or CDI supplies device configuration and does not by itself establish the capabilities the workload needs.

## Scope

Applies to Linux regular, init and ephemeral containers. Accelerator validation applies where the workload uses a device or RDMA path.

## Enforcement

- Primary Enforcement Point: Pod Security Admission at the Restricted level requires Linux containers to drop ALL and permits adding only NET_BIND_SERVICE. Use an approved workload-class policy for any Linux capability exception outside Restricted enforcement.
- Implementation Surface: Set container securityContext.capabilities with drop containing ALL and only approved additions. Verify admission coverage and measure the bounding and effective sets from the actual workload process. Record the device path tested and the approved retained capabilities. For NVIDIA CDI, verify the strategy supported by the pinned plugin, such as --device-list-strategy=cdi-annotations, and the actual driver, CDI-enabled runtime, device specification and workload operations.
- Owner Primary: Application Development teams
- Owner Supporting: Platform Engineering; AI/ML Platform team; Security Engineering
