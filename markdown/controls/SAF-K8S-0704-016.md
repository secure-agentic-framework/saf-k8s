# SAF-K8S-0704-016 - Effective Kubernetes API entitlement review and drift remediation

- Domain: D07 - Storage, Multi-tenancy, and Resource Governance
- Knowledge Area: 7.4 - Cloud Provider Security Integration
- Maturity: Practitioner
- Classification: baseline

## Statement

Reconcile approved Kubernetes API entitlements against effective authentication and authorization on material changes and at a documented cadence. Remediate unexplained differences and repeat scoped authorization checks.

## Objective

Confirm that observed Kubernetes API access continues to match approved entitlements over time.

## Rationale

Changes to identity membership, provider access policy, cluster authentication or authorization, Kubernetes bindings and default grants can change effective permissions. Periodic review detects differences when change signals are incomplete. Verify the resulting allow and deny decisions after remediation.

## Scope

Applies to governed managed and externally authenticated Kubernetes clusters. Review all relevant provider, identity and cluster authorization paths, emergency access, exceptions and explicitly recorded evidence gaps.

## Enforcement

- Primary Enforcement Point: Approved entitlement inventory, change-triggered and periodic reconciliation, and paired effective authorization checks after remediation.
- Implementation Surface: Compare dated provider, identity and Kubernetes configuration to the approved inventory. Track removed and missing grants, source identity, effective scope and reviewer actions. Reconcile through the applicable control plane and record the resulting permitted and denied access, along with any unaffected boundaries.
- Owner Primary: Cloud Platform Engineering
- Owner Supporting: Security Engineering; Platform Engineering
