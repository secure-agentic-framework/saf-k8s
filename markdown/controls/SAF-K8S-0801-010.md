# SAF-K8S-0801-010 - Admission validation of authorized GPU resource requests

- Domain: D08 - GPU, Accelerator, and Confidential Computing
- Knowledge Area: 8.1 - GPU Device Plugins and Resource Allocation
- Maturity: Practitioner
- Classification: ai-specific

## Statement

Validate accelerator requests before scheduling against approved workload submitters or controller ownership, allowable resource profiles and quantities. Apply effective namespace quotas to governed extended resources and verify admitted allocation through the installed device stack.

## Objective

Limit admitted accelerator requests to approved scopes and budgets and verify the intended resource is allocated by the deployed stack.

## Rationale

Identity and profile policy, namespace quota, scheduling, and runtime device allocation enforce different boundaries. Validate the actual admission fields and resource names used by the installed plugin, including applicable container types and workload controllers.

## Scope

Applies to governed accelerator workloads, Pod and supported workload-controller submission paths, approved profile resources, quantity limits and namespaces. Review applicable alternate scheduling or allocation interfaces.

## Enforcement

- Primary Enforcement Point: Pod admission policy, effective extended-resource quota and observed scheduler and device allocation behavior.
- Implementation Surface: Use approved identity and ownership rules and validate actual resource request and limit fields for covered containers. Set requests-prefixed namespace quotas for applicable extended resources. Verify approved, unapproved and over-quota outcomes and observe an authorized allocation with the intended driver and plugin.
- Owner Primary: ML Platform Engineering
- Owner Supporting: Platform Engineering; Security Engineering
