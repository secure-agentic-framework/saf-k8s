# SAF-K8S-0801-004 - vGPU virtualization security controls

- Domain: D08 - GPU, Accelerator, and Confidential Computing
- Knowledge Area: 8.1 - GPU Device Plugins and Resource Allocation
- Maturity: Practitioner
- Classification: ai-specific

## Statement

For virtualized GPU worker nodes, approve and enforce a vendor-supported virtualization mode, profile, software combination and allocation policy. Verify the documented isolation and resource properties and track relevant host and guest security updates and exceptions.

## Objective

Constrain virtual GPU assignment to supported configurations with independently evidenced isolation and capacity properties.

## Rationale

Hypervisor mediation, vendor partition mode, host and guest driver compatibility and Kubernetes scheduling address different layers. Supported modes can provide different memory, compute and fault guarantees. A configured profile or scheduled resource alone does not establish host or cross-VM isolation.

## Scope

Applies to governed Kubernetes worker VMs using virtualized accelerators, including managed offerings. Record product, mode, hardware, hypervisor, host and guest software versions, license support, versioned vendor evidence, approved assignment and exceptions.

## Enforcement

- Primary Enforcement Point: Approved host and guest platform compatibility, hypervisor policy, and independent review of observed device assignment and isolation.
- Implementation Surface: Maintain a versioned support and assignment record. Verify applicable platform security updates, hypervisor-mode isolation, relevant guest and host configuration and approved observed allocation and capacity. Separately validate Kubernetes resource exposure, admission and namespace quotas where used.
- Owner Primary: GPU Infrastructure Engineering
- Owner Supporting: Virtualization Engineering; ML Platform Engineering; Security Engineering
