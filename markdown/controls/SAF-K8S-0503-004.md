# SAF-K8S-0503-004 - Internal load balancer annotation enforcement

- Domain: D05 - Network Security and Communication
- Knowledge Area: 5.3 - Ingress, Egress, and DNS Hardening
- Maturity: Practitioner
- Classification: baseline

## Statement

Require the provider and controller's approved internal scheme for LoadBalancer Services unless an authorized exposure exception permits an internet-facing scheme. Require approved source ranges on public exceptions and verify effective restrictions on the deployed load balancer.

## Objective

Prevent unintended exposure of Kubernetes services to the public internet by enforcing internal load balancer annotations as the default for all LoadBalancer services.

## Rationale

LoadBalancer scheme defaults vary by provider, controller and configuration. Require an explicit scheme to make the intended exposure reviewable. Verify source range restrictions using the provider's reconciled load balancer and effective network rules.

## Scope

Applies to all production Kubernetes clusters using cloud provider LoadBalancer services. Covers internal annotation enforcement and source IP restriction for approved external services. Service type admission restrictions (blocking LoadBalancer, NodePort, ExternalIP) are addressed by SAF-K8S-0505-002.

## Enforcement

- Primary Enforcement Point: Admission controller policies enforcing internal load balancer annotations on LoadBalancer services.
- Implementation Surface: Use the installed controller's current fields. Use service.beta.kubernetes.io/aws-load-balancer-scheme with internal for current AWS Load Balancer Controller and EKS Auto Mode, networking.gke.io/load-balancer-type with Internal on GKE, or service.beta.kubernetes.io/azure-load-balancer-internal with true on AKS. Enforce approved values and authorized exceptions on Service creation and updates. Require approved spec.loadBalancerSourceRanges for external exceptions and verify controller support and effective network rules.
- Owner Primary: Platform Engineering
- Owner Supporting: Network Engineering; Security Engineering
