# SAF-K8S-0505-007 - Administrative API server access path via bastion or VPN

- Domain: D05 - Network Security and Communication
- Knowledge Area: 5.5 - API Server and Service Exposure Protection
- Maturity: Practitioner
- Classification: baseline

## Statement

Route human and automation Kubernetes administrative requests through an approved private management path such as a bastion, VPN, or provider-supported gateway. Enforce path access, verify the Kubernetes identity, and account for every enabled management route.

## Objective

Ensure human and automation administrators reach the API server only through controlled private access paths.

## Rationale

Managed access paths support access decisions and audit evidence at an administrative boundary. Public endpoint source restrictions and application authentication establish different properties. Verify admission to the intended path and correlate it with the Kubernetes operation.

## Scope

Applies to production administrative endpoints and non-production administration with production access. Inventory direct API endpoints and provider-mediated paths. Verify the path used by human operators, automation, and support identities and document approved exceptions.

## Enforcement

- Primary Enforcement Point: Bastion host access controls, VPN access controls, and equivalent managed private administrative access pathways.
- Implementation Surface: Enforce operator authentication, applicable multifactor requirements and approved network routing at the selected gateway or bastion. Use scoped workload identities for automation. Verify the permitted path and expected denials, inventory provider management-plane actions, and collect access and API audit records with the identity, target, decision and expected request correlation.
- Owner Primary: Platform Engineering
- Owner Supporting: Network Engineering; Security Engineering; Cloud Platform Engineering
