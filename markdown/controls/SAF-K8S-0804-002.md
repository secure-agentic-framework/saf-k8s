# SAF-K8S-0804-002 - Remote attestation for TEE integrity verification

- Domain: D08 - GPU, Accelerator, and Confidential Computing
- Knowledge Area: 8.4 - Confidential Computing for AI Workloads
- Maturity: Advanced
- Classification: ai-specific

## Statement

Verify fresh confidential workload evidence using approved platform trust roots, reference values and appraisal policy. Bind the appraisal to the intended hardware, workload, challenge and sensitive use. Deny sensitive resources or processing when applicable evidence is untrusted, stale or outside the approved scope.

## Objective

Make sensitive data and resource use conditional on a verified, configuration-specific confidential workload claim.

## Rationale

Cryptographic evidence verification and relying-party policy appraise specific measured state. They do not establish absence of all tampering. Runtime placement and CPU, GPU and workload evidence can require different verification sources.

## Scope

Applies to governed confidential workload profiles and supported attestation paths. Record applicable CPU, accelerator, runtime and workload claims, trust roots, reference values and freshness requirements, and verify invalid or unavailable evidence handling.

## Enforcement

- Primary Enforcement Point: Approved evidence verifier and relying-party policy controlling sensitive use, with scoped evidence renewal and revocation.
- Implementation Surface: Verify signature and collateral, reference measurements, trust policy, freshness and binding for applicable evidence. Define an attributable sensitive-use gate and verify rejected, accepted, stale and reused evidence handling as applicable. Reassess according to the supported workload lifecycle and retain sanitized decision evidence.
- Owner Primary: Security Engineering
- Owner Supporting: ML Platform Engineering; GPU Infrastructure Engineering; Key Management
