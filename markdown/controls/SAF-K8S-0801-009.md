# SAF-K8S-0801-009 - Restrict access to published accelerator inventory and topology metadata

- Domain: D08 - GPU, Accelerator, and Confidential Computing
- Knowledge Area: 8.1 - GPU Device Plugins and Resource Allocation
- Maturity: Practitioner
- Classification: ai-specific

## Statement

Minimize sensitive accelerator metadata published to users and workloads. Restrict Node API reads to approved principals and review other interfaces that expose accelerator inventory, topology or placement. Verify separately any narrower disclosure controls.

## Objective

Reduce unnecessary disclosure of accelerator details and placement information while preserving required scheduling and operations.

## Rationale

Node labels and status may contain accelerator inventory and allocatable counts. Kubernetes RBAC governs access to Node objects and operations. Other resources, including visible Pod placement and provider-specific reporting, have independent disclosure boundaries.

## Scope

Applies to clusters publishing governed accelerator details through Node labels or status, feature-discovery outputs, or authorized provider and device interfaces. Document required operator reads, protected fields, alternative interfaces and exceptions.

## Enforcement

- Primary Enforcement Point: Metadata publication and whole-object Node authorization, with separate controls for selective disclosure and other interfaces.
- Implementation Surface: Inventory actual enabled discovery and device plugin outputs. Restrict Node get, list and watch per approved principal and verify effective decisions. Review placement and external telemetry separately and use an approved minimized view when sharing selected fields.
- Owner Primary: ML Platform Engineering
- Owner Supporting: Platform Engineering; Security Engineering
