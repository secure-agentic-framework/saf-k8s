# SAF-K8S-0503-005 - DNS exfiltration detection

- Domain: D05 - Network Security and Communication
- Knowledge Area: 5.3 - Ingress, Egress, and DNS Hardening
- Maturity: Practitioner
- Classification: baseline

## Statement

Enable query logging on the approved cluster DNS path and use a detection pipeline to alert on reviewed DNS anomaly signals. Verify alert coverage and use separate enforcement controls where the organization requires prevention.

## Objective

Detect suspicious DNS activity and provide actionable evidence for incident response.

## Rationale

CoreDNS query logging supplies observations for a detector. Validate the signals against normal traffic and representative harmless fixtures. Logging and alerting do not enforce DNS or network policy.

## Scope

Applies to all production clusters with CoreDNS. DNS query logs must be forwarded to a centralized analysis platform. Detection rules must cover DNS tunneling indicators including high-entropy subdomain labels, anomalous query volume, and unusual record types.

## Enforcement

- Primary Enforcement Point: DNS query log analysis pipelines and SIEM detection rules for DNS tunneling indicators.
- Implementation Surface: Enable CoreDNS query logging on the intended path and forward the approved fields to the detection pipeline. Define and test alert thresholds, scope, suppression and normal-traffic behavior. Review practical coverage and data retention. Verify authorized DNS routing and enforcement separately under SAF-K8S-0503-015.
- Owner Primary: Security Operations
- Owner Supporting: Network Engineering; Platform Engineering
