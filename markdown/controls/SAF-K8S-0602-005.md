# SAF-K8S-0602-005 - Notary v2 OCI signature artifact registry integration

- Domain: D06 - Supply Chain, Images, and Admission Control
- Knowledge Area: 6.2 - Image Signing and Admission Enforcement
- Maturity: Practitioner
- Classification: baseline

## Statement

For each in-scope Notation registry, store each signature artifact in the corresponding image repository and verify discovery from the exact subject manifest digest. Validate the OCI Referrers API or the Referrers Tag fallback for each supported registry and client pair.

## Objective

Keep OCI signatures discoverable for their exact immutable subject digests throughout supported registry operations.

## Rationale

Registry integration for notation signatures is distinct from trust policy governance and admission verification. If signatures are stored outside OCI artifact flows or drift from image manifests, verification becomes brittle and signature discovery can fail across registries and toolchains.

## Scope

Applies to OCI stores that publish or replicate Notation signatures and clusters that consume them. Record the registry and client versions, native discovery or tag fallback, and applicable repositories and replication paths.

## Enforcement

- Primary Enforcement Point: Registry-level signature artifact storage configuration and notation registry integration.
- Implementation Surface: Verify the signature manifest subject descriptor, discovery and successful verification from the exact image digest. Test API and supported fallback as applicable and verify propagation, retention, garbage collection and registry replication separately.
- Owner Primary: Security Engineering
- Owner Supporting: Platform Engineering; DevSecOps / Release Engineering
