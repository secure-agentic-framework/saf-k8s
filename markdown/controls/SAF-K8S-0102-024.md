# SAF-K8S-0102-024 - etcd backup repository access audit logging

- Domain: D01 - Control Plane and Cluster Hardening
- Knowledge Area: 1.2 - etcd and Cluster State Protection
- Maturity: Foundational
- Classification: baseline

## Statement

Generate and retain attributable records for defined access events to governed etcd backups and restore copies at each system that mediates access. Verify applicable success and denial coverage, protected delivery and retention, and document unsupported events and compensating evidence.

## Objective

Reconstruct backup and restore-media access from attributable, time-stamped events with known coverage and observed delivery.

## Rationale

Kubernetes API auditing covers configured API requests. Repository object access, file operations and offline custody require evidence at their own access boundaries. Durable logging and independently enforced authorization support investigation.

## Scope

Applies to governed production etcd backups and restore copies in repositories, snapshot services, mounted storage and offline media. Include ordinary, automation, provider and exceptional paths and applicable data and configuration actions.

## Enforcement

- Primary Enforcement Point: Actual API, repository, host or media recording points and protected log collection with scope, delivery and retention checks.
- Implementation Surface: Inventory covered paths and selected events. Exercise representative permitted and denied actions, recording actor, target, operation, outcome and time. Correlate across sources where possible. Verify delivery, integrity protection, retention, retrieval and detection of pipeline failure.
- Owner Primary: Platform Engineering
- Owner Supporting: Security Engineering; Backup and Recovery Operations
