# SAF-K8S-0205-011 - Node firewall audit and change governance

- Domain: D02 - Node, Runtime, and OS Security
- Knowledge Area: 2.5 - kube-proxy and Node Networking Security
- Maturity: Practitioner
- Classification: baseline

## Statement

Maintain an approved, versioned baseline for each applicable node firewall plane. At defined intervals and after approved changes, compare effective observed rules with the baseline. Record authorization, drift, exceptions and remediation decisions.

## Objective

Detect unauthorized or unexpected firewall rule changes and make approved changes and their results reviewable.

## Rationale

Host firewall, provider and CNI policy can change independently. Approval records show authorized intent, while observed effective configuration and change provenance provide separate audit evidence.

## Scope

Applies to governed production node and provider firewall planes with named change and observation owners. Define collection cadence, stable comparison semantics, retained evidence, approved exceptions and escalation criteria.

## Enforcement

- Primary Enforcement Point: Firewall change approval and effective read-only state collection, reconciliation, and resolved drift records.
- Implementation Surface: Record approved baseline provenance and exact scope. Reconcile normalized effective snapshots, exercise a controlled mismatch and authorized recovery, retain independent evidence, and verify periodic execution and accountable exceptions in production.
- Owner Primary: Network Engineering
- Owner Supporting: Platform Engineering; Cloud Infrastructure; Security Engineering
