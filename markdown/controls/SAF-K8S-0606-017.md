# SAF-K8S-0606-017 - CNCF lifecycle phase security coverage

- Domain: D06 - Supply Chain, Images, and Admission Control
- Knowledge Area: 6.6 - CI/CD and GitOps Pipeline Security
- Maturity: Practitioner
- Classification: baseline

## Statement

For each governed Kubernetes delivery pipeline enforce locally required checks at the Develop, Distribute, and Deploy transitions. Bind each decision to the evaluated artifact. Address Runtime as the fourth CNCF lifecycle phase with separately owned operational checks and response evidence.

## Objective

Identify the checks and admission or promotion decisions at each delivery transition and verify applicable runtime controls after deployment.

## Rationale

CNCF TAG Security describes four continuous lifecycle phases named Develop, Distribute, Deploy, and Runtime. This SAF control defines local transition checks for the first three and requires separate runtime operating evidence.

## Scope

Applies to selected CI or GitOps delivery paths and their governed Kubernetes artifacts. Document local phase mappings and control applicability, and identify which operating environments and runtime checks follow deployment.

## Enforcement

- Primary Enforcement Point: CI and delivery transition gates, cluster admission, and documented Runtime monitoring and response.
- Implementation Surface: Map required pre-runtime checks to their actual CI, distribution and deployment boundaries. Retain pass or fail evidence for the exact artifact or configuration, prevent progression after a required check fails, and assess Runtime separately with deployed identity, policy, telemetry and response evidence appropriate to the workload.
- Owner Primary: DevSecOps / Release Engineering
- Owner Supporting: Security Engineering; Platform Engineering
