# SAF-K8S-0909-005 - RAG prompt injection defense

- Domain: D09 - AI Workload Security: Training, Serving, and Pipelines
- Knowledge Area: 9.9 - RAG Infrastructure Security
- Maturity: Practitioner
- Classification: ai-specific

## Statement

Treat retrieved records as untrusted data when assembling model requests. Verify source and record constraints, preserve program-controlled instruction roles, and independently authorize any consequential actions. Evaluate and monitor deployed model and tool behavior.

## Objective

Reduce indirect instruction risks from retrieval and preserve independently enforced limits on downstream actions.

## Rationale

Retrieved content is an additional untrusted input. Structured request assembly and source checks reduce the opportunities to grant it application authority. Model behavior and downstream action safety require separate observations.

## Scope

Applies to retrieval-to-model serialization, model and tool pathways, validation and monitoring for governed Kubernetes-hosted applications. Include alternate request paths and data transformations.

## Enforcement

- Primary Enforcement Point: The application request assembly boundary and the independently governed output and action interfaces.
- Implementation Surface: Verify trusted source metadata and exact record validation, keep retrieved data separate where the API supports it, enforce independent authorization for actions, and measure deployment-specific behavior, permitted task quality and actual monitoring outcomes.
- Owner Primary: ML Platform Engineering
- Owner Supporting: Security Engineering; Application Security
