# SAF-K8S-0204-001 - Runtime security tool deployment for syscall and network monitoring

- Domain: D02 - Node, Runtime, and OS Security
- Knowledge Area: 2.4 - Runtime Threat Detection
- Maturity: Practitioner
- Classification: baseline

## Statement

Deploy and operate a supported runtime telemetry source for governed Kubernetes compute classes. Define required process, file and network events independently. Verify sensor coverage, health, loss and delivery, and record approved exceptions and alternative evidence.

## Objective

Observe selected runtime actions and know which compute classes and event types have trustworthy telemetry.

## Rationale

Runtime instrumentation can observe selected kernel or workload events that API audit and application logs do not capture. Event coverage, attribution and production cost depend on the tool, driver, configuration, operating system and runtime. Signal collection, alert decisions and delivery require separate evidence.

## Scope

Applies to governed node and workload classes. Inventory operating system, architecture, kernel, runtime, provider responsibility, required signals, exclusion rationale and resource limits.

## Enforcement

- Primary Enforcement Point: Supported sensor deployment and effective event configuration, with runtime evidence and health reconciliation against the complete governed inventory.
- Implementation Surface: Exercise benign expected and out-of-scope activity for each required signal. Verify identities, timestamps, source version, availability, approved least privilege, event rate and loss, data handling and receipt by the intended destination. Document constraints of each tool and managed alternative.
- Owner Primary: Security Engineering
- Owner Supporting: Platform Engineering; Security Operations (SOC)
