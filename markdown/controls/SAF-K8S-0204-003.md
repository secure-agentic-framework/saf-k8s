# SAF-K8S-0204-003 - Container filesystem drift detection

- Domain: D02 - Node, Runtime, and OS Security
- Knowledge Area: 2.4 - Runtime Threat Detection
- Maturity: Practitioner
- Classification: baseline

## Statement

For governed container workloads, define approved image-backed paths and writable exceptions. Use a supported integrity comparison or runtime change detector for selected paths. Verify image identity, detected unauthorized changes and alert delivery. Govern read-only root enforcement, process events and library loading as separate observations.

## Objective

Detect relevant changes from a known container filesystem baseline and distinguish approved writable state.

## Rationale

Image provenance establishes the approved baseline. A write or file-open event alone does not prove a persistent content change, successful execution or a library load. A read-only root protects the relevant mount boundaries while permitted volumes have independent behavior.

## Scope

Applies to selected governed container and node classes. Identify source image digests, covered filesystem and mount paths, approved ephemeral or persistent state, sensor limitations, unavailable baselines and exceptions.

## Enforcement

- Primary Enforcement Point: Effective runtime integrity comparison or change telemetry tied to an approved image identity and explicit monitored and excluded paths.
- Implementation Surface: Compare approved and observed content or path state using harmless owned files. Confirm narrow writable exceptions, retain positive and negative tests, verify relevant monitoring and delivery, and exercise read-only root or process and loader signals independently where required.
- Owner Primary: Security Engineering
- Owner Supporting: Platform Engineering; Application Development
