# SAF-K8S-0906-002 - Large-scale data integrity verification

- Domain: D09 - AI Workload Security: Training, Serving, and Pipelines
- Knowledge Area: 9.6 - Training Data Integrity and Poisoning Defense
- Maturity: Practitioner
- Classification: ai-specific

## Statement

Verify the exact approved dataset version before training. Bind the expected inventory, immutable segment identifiers, lengths and digests to an independently trusted manifest. Use a canonical hierarchical commitment for distributed or incremental checks when it fits the verification model. Select and exercise recovery independently.

## Objective

Detect missing, changed or substituted segments before training consumes the dataset and exercise the storage recovery policy.

## Rationale

A validated streaming digest detects changed bytes relative to a trusted expectation. Partitioning and tree commitments support independent and incremental checks. Durability and agreement with an authorized dataset version require separate evidence.

## Scope

Applies to governed datasets on persistent volumes, distributed file systems and object or artifact stores. Set segment size, verification cadence and proof mode based on the workload and storage. Verify the deployment and recovery at operational scale.

## Enforcement

- Primary Enforcement Point: Dataset approval and manifest provenance, pre-consumption integrity verification and the storage recovery policy.
- Implementation Surface: Record versioned storage identifiers in an authenticated manifest. Verify exact inventory and bounded streaming segment hashes and validate any tree root or inclusion proofs against the trusted commitment. Fail closed before training and exercise recovery on the real storage.
- Owner Primary: Data Engineering
- Owner Supporting: Storage Engineering; ML Platform Engineering
