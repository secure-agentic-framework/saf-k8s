# SAF-K8S-0601-008 - CI/CD build-time container image vulnerability scanning

- Domain: D06 - Supply Chain, Images, and Admission Control
- Knowledge Area: 6.1 - Container Image and Registry Security
- Maturity: Practitioner
- Classification: ai-specific

## Statement

Scan each governed candidate image before registry promotion. Bind trustworthy scan evidence to the exact image manifest digest and fail closed for unavailable, outdated or mismatched evidence and unmitigated findings at the approved severity threshold. Allow only explicitly scoped, authorized and expiring exceptions.

## Objective

Prevent governed build paths from publishing unreviewed images or images with unresolved blocking component findings.

## Rationale

A scanner finding and the promotion decision have distinct responsibilities. The gate requires evidence for the exact artifact, including valid completion and advisory freshness. Restrict other writers independently.

## Scope

Applies to governed image build and import paths and applicable architecture manifests, including native accelerator and model runtime dependencies. Verify actual scanner coverage, evidence carriage and access to the registry.

## Enforcement

- Primary Enforcement Point: Trusted build scan evidence, promotion decision and restricted registry push credentials.
- Implementation Surface: Scan packaged images, bind evidence to immutable manifest and scan configuration, validate completeness and age, and reject blocking findings before push. Verify scoped exception expiry, exact manifest publication and absent blocked tags independently.
- Owner Primary: DevSecOps / Release Engineering
- Owner Supporting: ML Platform Engineering; Security Engineering
