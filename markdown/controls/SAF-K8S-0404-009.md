# SAF-K8S-0404-009 - Compromised certificate revocation and re-issuance execution

- Domain: D04 - Identity, Access, and Secrets Management
- Knowledge Area: 4.4 - Certificate Management
- Maturity: Practitioner
- Classification: baseline

## Statement

When a governed private key is compromised, execute an approved issuer-side revocation or applicable invalidation procedure. Issue a replacement using an independently generated key where continued use is needed. Verify the disposition and affected relying-party rejection within the response window.

## Objective

Remove authorization associated with compromised certificate credentials and enable approved replacement under documented time and scope limits.

## Rationale

A new certificate leaves the earlier serial valid unless the configured authority and relying parties enforce an effective retirement mechanism. Some supported Kubernetes authentication paths require separate identity, trust, authorization or rotation actions.

## Scope

Applies to governed cluster and workload certificates following confirmed key compromise. Distinguish revocation publication, relying-party enforcement, unsupported cases and alternate response. Validate recovery under SAF-K8S-0404-010.

## Enforcement

- Primary Enforcement Point: Approved issuing authority action, verified distinct replacement key and a relying-peer rejection or independently verified alternate invalidation.
- Implementation Surface: Record the issuer, affected serial or identity, report time, required deadline, revocation evidence and applicable CRL or OCSP consumption. Exercise valid replacement and independent access. Define mitigation for clients or native endpoints without the required revocation behavior.
- Owner Primary: Platform Engineering
- Owner Supporting: Security Engineering; Security Operations
