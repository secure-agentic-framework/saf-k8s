# SAF-K8S-0202-011 - Node mandatory access control activation for container workloads

- Domain: D02 - Node, Runtime, and OS Security
- Knowledge Area: 2.2 - Container Runtime Security
- Maturity: Foundational
- Classification: baseline

## Statement

On governed supported nodes, require applicable enforcing AppArmor or SELinux policies and verify effective workload confinement. Track unsupported cases and approved exceptions. Verify seccomp under its separate control.

## Objective

Constrain intended workload operations with an effective node MAC policy and attributable runtime evidence.

## Rationale

A workload declaration, enabled node policy and effective container label or profile provide different evidence. Runtime and kernel support and enforcement mode determine the actual result. Seccomp applies a separate syscall filter.

## Scope

Applies to governed production node pools and workloads using supported mandatory access control. Inventory AppArmor or SELinux modes, policy sources and updated labels, runtime support, authorized exceptions and provider-operated paths.

## Enforcement

- Primary Enforcement Point: Effective kernel MAC enforcement and runtime policy assignment, with approved workload and node eligibility.
- Implementation Surface: Verify applicable node enforcement mode, required policy and label loading, effective workload label or profile, and approved expected decisions using inert files and supported runtime evidence. Record remaining gaps rather than inferring enforcement from a manifest alone.
- Owner Primary: Security Engineering
- Owner Supporting: Platform Engineering; OS/Infrastructure
