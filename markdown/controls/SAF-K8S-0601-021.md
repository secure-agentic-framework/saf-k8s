# SAF-K8S-0601-021 - Container registry trusted-source network restriction

- Domain: D06 - Supply Chain, Images, and Admission Control
- Knowledge Area: 6.1 - Container Image and Registry Security
- Maturity: Practitioner
- Classification: baseline

## Statement

Restrict container and OCI registry connections to approved network sources using the mechanisms available in the deployed environment. Verify trusted access and effective denial at each registry entry point.

## Objective

Reduce registry network exposure and preserve access through documented approved paths.

## Rationale

Network policy can prevent unapproved sources from reaching the registry. Request authentication and repository authorization are separate controls.

## Scope

Applies to governed registries, mirrors and caches. Inventory private and public resolution, direct endpoints, service paths and management interfaces. Use approved cache and authentication policy where applicable.

## Enforcement

- Primary Enforcement Point: Effective ingress or connection policy at each registry endpoint and associated network boundary.
- Implementation Surface: Verify private endpoint, firewall, CIDR or workload-selector enforcement as applicable. Probe both permitted and denied routes and retain exact path evidence.
- Owner Primary: Platform Engineering
- Owner Supporting: Security Engineering; DevSecOps / Release Engineering
