# SAF-K8S-1006-008 - NIST SP 800-218A AI/ML profile alignment for Kubernetes AI development

- Domain: D10 - Observability, Incident Response, and Governance
- Knowledge Area: 10.6 - Compliance and Governance
- Maturity: Advanced
- Classification: ai-specific

## Statement

Organizations developing generative AI or dual-use foundation models, or developing Kubernetes software that integrates those models, must use NIST SP 800-218A with SSDF v1.1 to select and document applicable secure development tasks based on risk. Map the selected tasks to owned processes and controls for applicable training data integrity and provenance, model and component provenance, and ML pipeline security.

## Objective

Maintain a reviewable mapping between applicable NIST SP 800-218A tasks, owned development practices, supporting evidence, and unresolved secure development gaps.

## Rationale

NIST SP 800-218A supplements SSDF v1.1 with recommendations and considerations specific to generative AI and dual-use foundation model development. Teams select and adapt tasks based on role, risk, applicability, and feasibility. Document any local interpretation of training, model weights, and pipeline provenance alongside the applicable task and evidence.

## Scope

Applies to the secure development of generative AI or dual-use foundation models for Kubernetes and to software development that integrates those models. Development includes data sourcing, design, training, fine-tuning, evaluation, and model integration. Assess cybersecurity practices for data used in model development with the July 2024 profile. Use relevant operational and data lifecycle controls for AI system deployment, operation, and broader data governance.

## Enforcement

- Primary Enforcement Point: AI/ML secure development profile documentation and AI-specific CI/CD compliance checks.
- Implementation Surface: Maintain a versioned assessment identifying the model category, team role, development activities, and Profile edition. Record task applicability with rationale, map applicable tasks to owned SAF-K8S controls and secure development practices, link approved evidence, and track gaps with owners and review dates. Identify local adaptations in the mapping and update it when the model, development process, or risk changes.
- Owner Primary: GRC/Compliance
- Owner Supporting: AI/ML Engineering; DevOps/Platform Engineering; Security Architecture
