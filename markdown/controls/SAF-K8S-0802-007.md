# SAF-K8S-0802-007 - Device plugin enrollment and registration telemetry reconciliation

- Domain: D08 - GPU, Accelerator, and Confidential Computing
- Knowledge Area: 8.2 - GPU Driver, Library, and Toolkit Security
- Maturity: Practitioner
- Classification: ai-specific

## Statement

Restrict node-local device-plugin registration access to approved platform components. Maintain an authorized deployment and resource inventory and reconcile available registration, socket lifecycle, device health and node allocation evidence.

## Objective

Limit unapproved influence over device allocation and identify discrepancies among actual deployment, registration, device reports and independently verified inventory.

## Rationale

Kubernetes registration is a local interface whose request describes the plugin endpoint and resource. Plugin-reported health drives Kubernetes resource availability. Identity assurance and independent device validation require additional controls and evidence.

## Scope

Applies to governed Kubernetes nodes with device plugins, their approved platform components, node-local telemetry, reported resources, and independent host and device observations.

## Enforcement

- Primary Enforcement Point: Host access policy, approved deployment provenance and reconciliation of node-local and Kubernetes inventory.
- Implementation Surface: Verify approved plugin deployments and actual host access policy. Collect available registration and health evidence with node identity, source, time and monitoring coverage. Reconcile source records, resource and health changes, and independently sourced expected inventory and record unknown or inconsistent observations.
- Owner Primary: Platform Engineering
- Owner Supporting: ML Platform Engineering; Security Engineering
