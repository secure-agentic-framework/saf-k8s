# SAF-K8S-0909-009 - Vector database authentication and collection-level access control

- Domain: D09 - AI Workload Security: Training, Serving, and Pipelines
- Knowledge Area: 9.9 - RAG Infrastructure Security
- Maturity: Practitioner
- Classification: ai-specific

## Statement

Require approved client authentication and enforce read, write and administrative permissions for each governed collection or equivalent scope. Verify controls on the effective listeners and API paths for the selected backend.

## Objective

Authorize each governed principal to perform only the approved vector data operations within its assigned scope.

## Rationale

Authentication establishes a caller or credential identity. Access to embeddings, metadata and mutations depends on separate operation and collection authorization. The available authorization surfaces differ by backend and deployment.

## Scope

Applies to client vector database interfaces and their applicable administration and service identity boundaries. Assess peer authentication in distributed deployments and encryption in their applicable controls.

## Enforcement

- Primary Enforcement Point: The live vector backend or an enforced approved authorization boundary for each client path.
- Implementation Surface: Enable approved authentication and define collection permissions for read, write and administration. Exercise unauthenticated and out-of-scope denials and in-scope access on the actual interfaces, including direct and proxy routes. Verify credential lifecycle and any privileged exceptions.
- Owner Primary: ML Platform Engineering
- Owner Supporting: Security Engineering; Infrastructure Engineering
