# SAF-K8S-0501-004 - CNI-specific network policy extensions

- Domain: D05 - Network Security and Communication
- Knowledge Area: 5.1 - Network Policies
- Maturity: Practitioner
- Classification: baseline

## Statement

Organizations using advanced CNI plugins must leverage CNI-specific policy extensions (such as Cilium CiliumNetworkPolicy or Calico GlobalNetworkPolicy) to enforce L7-aware network policies, FQDN-based filtering, and cluster-wide policy baselines that exceed the capabilities of standard Kubernetes NetworkPolicy.

## Objective

Extend network policy enforcement beyond L3/L4 Kubernetes-native NetworkPolicy to include application-layer visibility and cluster-wide policy baselines.

## Rationale

Standard Kubernetes NetworkPolicy is limited to L3/L4 filtering and is namespace-scoped, which is insufficient for enforcing HTTP method restrictions, DNS-based destination controls, or cluster-wide security baselines. Without leveraging CNI-specific extensions, organizations lose the ability to inspect and filter application-layer traffic, leaving gaps in protocol-aware security enforcement.

## Scope

Applies to production clusters running CNI plugins that support extended policy resources (Cilium, Calico, or equivalent). Organizations using managed Kubernetes with limited CNI choice must document compensating controls. Global policies must not conflict with namespace-level policies.

## Enforcement

- Primary Enforcement Point: CNI-specific custom resource definitions (CiliumNetworkPolicy, CiliumClusterwideNetworkPolicy, Calico GlobalNetworkPolicy) applied via GitOps or admission control.
- Implementation Surface: CiliumNetworkPolicy and CiliumClusterwideNetworkPolicy CRDs (L7 HTTP rules, toFQDNs, DNS proxy, identity-based policies), Calico GlobalNetworkPolicy and Calico Enterprise policy resources (destination.domains, Envoy-based L7 filtering), GitOps pipelines for cluster-wide baseline policy deployment, and CNI-specific CRD management via admission control.
- Owner Primary: Network Engineering
- Owner Supporting: Platform Engineering; Security Engineering
