# SAF-K8S-0909-014 - Document provenance and integrity validation before RAG chunking and indexing

- Domain: D09 - AI Workload Security: Training, Serving, and Pipelines
- Knowledge Area: 9.9 - RAG Infrastructure Security
- Maturity: Practitioner
- Classification: ai-specific

## Statement

Verify governed document provenance and integrity before chunking and indexing. Bind the exact document to an approved source and version using an authenticated manifest or equivalent approved evidence. Persist the applicable provenance record with the derived data.

## Objective

Accept only approved document bytes and preserve their verifiable provenance during retrieval data preparation.

## Rationale

Source access and a computed digest alone do not establish a document's provenance. Compare with a trusted binding and assess the applicable version and freshness before any derived data is written.

## Scope

Applies to document acceptance, chunking and index writes across ingestion routes, updates and retries. Assess repository access and classification separately.

## Enforcement

- Primary Enforcement Point: The document approval and byte verification gate before any chunk or index write.
- Implementation Surface: Verify the trusted issuer, document bytes and approved source or revision, and any applicable freshness rule. Observe that denied inputs do not progress to chunking or index writes. Link the source receipt and valid derived artifacts on the approved path.
- Owner Primary: Data Engineering
- Owner Supporting: Security Engineering; ML Platform Engineering
