# SAF-K8S-0704-013 - Unified cloud and Kubernetes audit source onboarding

- Domain: D07 - Storage, Multi-tenancy, and Resource Governance
- Knowledge Area: 7.4 - Cloud Provider Security Integration
- Maturity: Practitioner
- Classification: baseline

## Statement

Route required provider and Kubernetes API audit record classes from each governed managed cluster to an approved monitoring plane. Verify producer coverage, collector enrollment and destination receipt separately and keep source identities distinct.

## Objective

Make selected audit records queryable for managed Kubernetes security operations with traceable source identities, delivery evidence and documented coverage.

## Rationale

Provider and Kubernetes audit streams have different producers, record classes, configuration and delivery behavior. A common monitoring destination facilitates cross-source analysis. Verify observed receipt, exclusions, gaps and retention for each source and destination independently.

## Scope

Applies to each governed managed cluster and its approved monitoring destinations. Document required source classes, producer configuration and exclusions, transport or collector enrollment, permissions, destination, coverage and retention.

## Enforcement

- Primary Enforcement Point: Provider and Kubernetes audit producer settings, authorized routing, and destination-side query and delivery verification.
- Implementation Surface: For each required stream document source identity, category, resource scope and audit policy. Verify the enrolled routing and expected identities and parse results at the destination using approved marker events. Monitor loss, lag and delivery failures where observable, and test retention and approved exceptions separately.
- Owner Primary: Security Engineering
- Owner Supporting: Cloud Platform Engineering; Platform Engineering; SOC
