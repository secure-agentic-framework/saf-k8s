# SAF-K8S-0301-005 - PSA exemption register and justification tracking

- Domain: D03 - Workload and Pod Security
- Knowledge Area: 3.1 - Pod Security Standards and Admission
- Maturity: Foundational
- Classification: ai-specific

## Statement

Organizations must maintain a formal register for workloads that require elevated privileges beyond their namespace PSS level, documenting the exact privileges required, justification, risk owner, and associated compensating controls for each exemption.

## Objective

Ensure privileged PSA exceptions are explicitly documented, justified, and reviewable rather than hidden inside namespace-wide privilege relaxations.

## Rationale

A formal register is necessary to track why exceptions exist, who owns them, and which workloads still need them. This documentation obligation is distinct from the enforcement of scoped exemption rules.

## Scope

Applies to all workloads requesting privileges beyond their namespace PSS level, including GPU device plugins, CNI agents, CSI drivers, log collectors, and monitoring DaemonSets. Each exemption must specify the exact privileges required and the compensating controls applied.

## Enforcement

- Primary Enforcement Point: Exemption Governance Process
- Implementation Surface: Maintain a version-controlled register linked to effective native PSA exemptions by namespace, RuntimeClass or authenticated API username. Native PSA exemptions skip enforce, audit and warn. Record separately applied workload-scoped admission controls, such as Gatekeeper or Kyverno rules that constrain ServiceAccount, labels and requested Pod fields. Verify compensating isolation for exempt workloads such as GPU device plugin, CNI, CSI and monitoring components. Audit exception records and exempt workload changes using scoped resources and verbs. Reserve RequestResponse for approved resources and actions with a documented evidence need. Use Metadata for Secrets and other credential-bearing resources.
- Owner Primary: Platform Engineering
- Owner Supporting: Security Engineering; AI/ML Platform team; Infrastructure team
