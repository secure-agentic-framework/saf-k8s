# SAF-K8S-0802-009 - GPU driver binary path file integrity monitoring

- Domain: D08 - GPU, Accelerator, and Confidential Computing
- Knowledge Area: 8.2 - GPU Driver, Library, and Toolkit Security
- Maturity: Advanced
- Classification: ai-specific

## Statement

Maintain a protected, versioned inventory and integrity baseline for the effective accelerator driver files. Detect and report unauthorized changes and verify any separately required pre-use appraisal.

## Objective

Detect drift in governed accelerator driver files and identify whether a separately verified control prevents use of changed files.

## Rationale

Driver file detection depends on an explicit inventory, trustworthy baseline and evidence from the actual filesystem. A read-only monitor can observe a mismatch after a file changes. Blocking use requires a separate enforcement mechanism and evidence.

## Scope

Applies to governed accelerator platforms and installation modes, including host-installed, operator-managed and provider-managed driver files where observable. Record covered paths, baseline sources, exclusions and exceptions.

## Enforcement

- Primary Enforcement Point: Effective host file monitoring against a protected baseline and separately verified appraisal where required.
- Implementation Surface: Map exact effective file paths and versions to a trusted package or approved build. Protect baseline and alert records, verify observed detection and approved replacement handling, and review actual pre-use appraisal scope independently if required.
- Owner Primary: Platform Engineering
- Owner Supporting: Security Engineering; GPU Infrastructure Engineering
