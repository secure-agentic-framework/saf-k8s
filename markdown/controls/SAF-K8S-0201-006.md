# SAF-K8S-0201-006 - Node system and kube reserved resource allocations

- Domain: D02 - Node, Runtime, and OS Security
- Knowledge Area: 2.1 - Kubelet and Node Configuration Hardening
- Maturity: Foundational
- Classification: baseline

## Statement

Configure and verify measured kubeReserved and systemReserved headroom for governed node pools. Verify Node Allocatable for the selected resources and independently validate any daemon cgroup placement and enforcement needed by the node baseline.

## Objective

Reserve documented capacity for system and Kubernetes daemons based on measured current and peak demand. Verify effective allocatable, applicable resource enforcement, workload recovery and daemon responsiveness in representative approved tests.

## Rationale

The kubelet accounts for selected reservations when it calculates Node Allocatable, which affects workload placement. Daemon cgroup placement and enforcement require separate settings. Measure contention and approved limits so the reservations and their enforcement support node workload and daemon requirements.

## Scope

Applies to applicable node pools and their OS, runtime and Kubernetes daemons. Review control plane, worker, provider-managed and accelerator node pools according to their supported resources, startup requirements and measured headroom. Review GPU device resources through their own controls.

## Enforcement

- Primary Enforcement Point: Node provisioning templates and kubelet configuration files specifying systemReserved and kubeReserved settings.
- Implementation Surface: KubeletConfiguration systemReserved, kubeReserved and enforceNodeAllocatable settings, approved cgroup paths when used, advertised Node Allocatable, and repeatable measurements of daemon and workload headroom, health and recovery.
- Owner Primary: Platform Engineering
- Owner Supporting: Workload Teams; Capacity Planning
