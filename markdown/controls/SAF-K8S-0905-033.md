# SAF-K8S-0905-033 - Pre-load model file structure and metadata validation

- Domain: D09 - AI Workload Security: Training, Serving, and Pipelines
- Knowledge Area: 9.5 - AI Supply Chain and Model Lifecycle
- Maturity: Practitioner
- Classification: ai-specific

## Statement

Validate model bytes before calling the format-specific loader. Require trusted size and format limits, schema and metadata policy, exact data bounds, and any format-specific operation restrictions. Fail closed and record the disposition.

## Objective

Stop unexpected or policy-violating model files at the intake boundary before the loader consumes their data.

## Rationale

A valid filename or supported format leaves the actual contents and application-specific metadata unverified. Early bounded checks reduce invalid and unapproved loading paths.

## Scope

Applies to model intake for serving, fine-tuning and training. Define and test the exact checks and loader versions for formats and routes actually used.

## Enforcement

- Primary Enforcement Point: Bounded preflight at the model intake and loader boundary.
- Implementation Surface: Verify format structure, size, types and offsets, expected metadata and any applicable operators against pinned policy. Bind the decision to exact bytes and retain sanitized rejection and approved-load evidence.
- Owner Primary: ML Platform Engineering
- Owner Supporting: Security Engineering; ML Engineering
