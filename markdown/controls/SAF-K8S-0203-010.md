# SAF-K8S-0203-010 - Minimal purpose-built node OS baseline

- Domain: D02 - Node, Runtime, and OS Security
- Knowledge Area: 2.3 - Host OS and Kernel Hardening
- Maturity: Foundational
- Classification: baseline

## Statement

Select an approved and supported Kubernetes node OS image with a reviewed inventory. Exclude components outside required Kubernetes, platform, security and authorized operations. Verify the selected image and effective node service behavior.

## Objective

Reduce the node OS software and service surface without removing required or approved operational functions.

## Rationale

A purpose-built or reduced OS image can limit unnecessary components. Its effective surface includes packages, services, accounts, extensions and management paths. Image immutability and upgrade support require independent evidence.

## Scope

Applies to governed node images and pools. Inventory the base artifact and version, packages, service and account policy, approved extensions, image lifecycle, provider ownership and applicable exceptions.

## Enforcement

- Primary Enforcement Point: Effective node image build, provider selection, image provenance, and observed software and required runtime behavior.
- Implementation Surface: Review the approved component inventory and actual image contents and running services. Exercise expected package or service exclusions while verifying Kubernetes functions. Document permissions, maintenance, recovered approved versions and provider evidence.
- Owner Primary: Platform Engineering
- Owner Supporting: OS/Infrastructure; Security Engineering
