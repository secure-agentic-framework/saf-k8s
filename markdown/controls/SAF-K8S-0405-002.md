# SAF-K8S-0405-002 - Privilege escalation detection and monitoring

- Domain: D04 - Identity, Access, and Secrets Management
- Knowledge Area: 4.5 - Identity Abuse Detection and Mitigation
- Maturity: Practitioner
- Classification: baseline

## Statement

Monitor governed authorization-change and privileged identity signals using approved event sources, detection policy and response targets. Verify attributable alerts for the selected RBAC mutations, denied operations and anomalous identity activity, and document source visibility gaps.

## Objective

Detect specified unexpected privileged behavior and deliver practicable evidence to the responsible responder within approved bounds.

## Rationale

Audit shows observed API requests and decisions. Runtime and issuer telemetry supply different signals. Administrative changes and credential activity need identity and policy context before they are classified as unauthorized or suspicious.

## Scope

Applies to governed production Kubernetes and its associated audit, identity and runtime sources. Identify covered event classes, managed-provider visibility, retention and the expected reviewer and response path.

## Enforcement

- Primary Enforcement Point: Actual audit and runtime telemetry, source-sensitive reviewed detection policy, and observed alert delivery and retention.
- Implementation Surface: Verify event selection, attribution, successful and denied changes, approved baselines, and legitimate access. Demonstrate alert generation and delivery with known public fixture events. Document gaps for issuer activity, file access, endpoint telemetry, signal latency and false positives.
- Owner Primary: Security Operations
- Owner Supporting: Security Engineering; Platform Engineering
