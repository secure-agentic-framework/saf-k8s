# SAF-K8S-0201-008 - Kubelet configuration and credential file ownership and permissions

- Domain: D02 - Node, Runtime, and OS Security
- Knowledge Area: 2.1 - Kubelet and Node Configuration Hardening
- Maturity: Foundational
- Classification: baseline

## Statement

Apply an approved ownership and permission baseline to the effective kubelet configuration, kubeconfig and referenced private credentials for each applicable node. Apply the version and distribution-specific requirements for each file class. Protect credential-bearing files and resolved key targets from unauthorized access and changes.

## Objective

Protect kubelet configuration, kubeconfig material, and node credential files from unauthorized local access or tampering through restrictive ownership and permission settings.

## Rationale

The kubelet selects configuration and authentication files by its effective settings. Treat a kubeconfig with private credentials and a rotating key target as sensitive files, and use the applicable benchmark and platform baseline for configuration files.

## Scope

Covers the effective kubelet configuration and kubeconfig, active bootstrap material, referenced private keys and their link and directory protections. Resolve responsibility by node pool. For provider-operated scope, require applicable evidence for those protections or record the unverified scope and any approved equivalent.

## Enforcement

- Primary Enforcement Point: Effective node file ownership, permissions and access controls, established in approved provisioning and checked through recurring metadata assessment.
- Implementation Surface: Inventory active paths and credential references. Apply file-specific owner and mode baselines, verify ACL and directory access, resolve rotating links, and record bootstrap state. For the CIS Kubernetes 1.12 example, the kubelet configuration and kubeconfig checks 4.1.5, 4.1.6, 4.1.9 and 4.1.10 use 0600 or more restrictive and root:root. Retain assessment, approved deviation and remediation records.
- Owner Primary: Platform Engineering
- Owner Supporting: Security Engineering; OS/Infrastructure
