# SAF-K8S-0908-002 - Inference API information exposure controls

- Domain: D09 - AI Workload Security: Training, Serving, and Pipelines
- Knowledge Area: 9.8 - Model Abuse and Extraction Prevention
- Maturity: Advanced
- Classification: ai-specific

## Statement

Enforce reviewed response field and error contracts at the inference API. Release diagnostic outputs such as logits, internal features or model metadata through an explicitly authorized path.

## Objective

Minimize inference response information according to assessed disclosure risk and approved caller needs.

## Rationale

Success bodies, error details and diagnostic metadata can disclose information beyond the public contract. The effective disclosure reduction depends on the model, configuration and served routes. Confirm authorized use and evaluate residual risks independently.

## Scope

Applies to production-facing inference success and error results and the related diagnostic serving paths. Inventory alternate routes and interfaces and verify their effective authorization controls.

## Enforcement

- Primary Enforcement Point: The serving response serializer and the actual diagnostic authorization boundary.
- Implementation Surface: Test exact response field allowlists for valid and invalid requests, and verify authentication and authorization for named diagnostic resources. Review errors, logs, route coverage, transport and useful legitimate output according to assessed risks.
- Owner Primary: Security Engineering
- Owner Supporting: ML Platform Engineering; API Platform Engineering
