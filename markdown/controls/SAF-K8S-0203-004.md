# SAF-K8S-0203-004 - Secure boot and verified boot chain enforcement

- Domain: D02 - Node, Runtime, and OS Security
- Knowledge Area: 2.3 - Host OS and Kernel Hardening
- Maturity: Foundational
- Classification: baseline

## Statement

Require supported verified boot for applicable governed node profiles. Verify effective enforcement against the approved trust policy and documented stage coverage. Define approved exceptions and separately governed measured-boot appraisal where applicable.

## Objective

Maintain an evidenced, configuration-specific boot trust chain for governed nodes.

## Rationale

Secure Boot and verified boot apply to specified stages and enrolled trust policy. Measured boot reports state for appraisal. Neither establishes unrestricted trust in the running node or in every subsequent component.

## Scope

Applies to governed production nodes with relevant platform support. Inventory effective firmware and trust policy, boot stages, provider responsibilities, approved image and keys, measured evidence where used and documented exceptions.

## Enforcement

- Primary Enforcement Point: Effective firmware or verified boot policy and trusted image and signing lifecycle, with separate attestation evidence where applicable.
- Implementation Surface: Record actual boot policy, image provenance and supported stage coverage. Verify approved boot and refusal of an unapproved inert image where feasible, remediation, key updates and fallback ownership. Evaluate provider and hardware evidence at the relevant boundary.
- Owner Primary: Cloud Infrastructure
- Owner Supporting: OS/Infrastructure; Security Engineering
