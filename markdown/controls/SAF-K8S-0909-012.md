# SAF-K8S-0909-012 - Context poisoning monitoring and incident response for RAG retrieval

- Domain: D09 - AI Workload Security: Training, Serving, and Pipelines
- Knowledge Area: 9.9 - RAG Infrastructure Security
- Maturity: Practitioner
- Classification: ai-specific

## Statement

Monitor governed vector index and retrieval state against approved integrity and change evidence. Alert on applicable discrepancies and verify containment, investigation and authorized recovery at the affected release boundaries.

## Objective

Detect unexpected retrieval state and contain the affected scope while preserving approved retrieval and incident evidence.

## Rationale

Index changes can persist across releases and affect retrieval. Detection alone does not establish that suspicious state was quarantined, that downstream release was blocked, or that recovery was authorized.

## Scope

Applies to approved integrity monitors, alert routing, scoped containment and investigation, and independently verified restoration. Account for monitoring timing and all affected consumption paths.

## Enforcement

- Primary Enforcement Point: The vector integrity monitor, incident receiver and actual quarantine and release enforcement.
- Implementation Surface: Verify approved change and digest references, alert receipt and triage, scoped hold or rollback, downstream rejection and approved recovery. Preserve enough minimal evidence to reconstruct the event and measure approved operating tolerance.
- Owner Primary: ML Platform Engineering
- Owner Supporting: Security Engineering; Security Operations
