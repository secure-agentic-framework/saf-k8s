# SAF-K8S-0909-013 - Approved source repository access control and allowlist enforcement for RAG ingestion

- Domain: D09 - AI Workload Security: Training, Serving, and Pipelines
- Knowledge Area: 9.9 - RAG Infrastructure Security
- Maturity: Practitioner
- Classification: ai-specific

## Statement

Authenticate governed ingestion workers to approved repositories and verify the repository, publisher and path against a trusted source policy before reading or accepting documents.

## Objective

Permit ingestion only from the source and paths approved for the worker and workflow.

## Rationale

A reachable repository or valid credential does not establish the approved ingestion scope. Verify repository identity, applicable allowed paths and actual destination behavior before producing derived data.

## Scope

Applies to repository identity, ingestion credentials, approved source and path policies and all intake routes. Verify document-level integrity and provenance under the applicable control.

## Enforcement

- Primary Enforcement Point: Repository read authorization and intake admission before source retrieval.
- Implementation Surface: Pin approved identities and paths, use scoped credentials, verify effective destinations and applicable redirects, and observe permitted and denied fetches and downstream writes. Monitor policy changes and alternate intake paths.
- Owner Primary: Data Engineering
- Owner Supporting: Security Engineering; ML Platform Engineering
