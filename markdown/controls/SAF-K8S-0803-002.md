# SAF-K8S-0803-002 - InfiniBand and RoCE fabric security controls

- Domain: D08 - GPU, Accelerator, and Confidential Computing
- Knowledge Area: 8.3 - High-Performance Interconnect Security
- Maturity: Advanced
- Classification: ai-specific

## Statement

Enforce and verify tenant segmentation for the fabric actually deployed. Verify approved Subnet Manager and partition enforcement for InfiniBand where applicable, and effective Ethernet or IP segmentation and admission for the applicable RoCE mode.

## Objective

Limit inter-tenant reachability using supported policy at the actual fabric data plane and management plane.

## Rationale

InfiniBand uses fabric and partition mechanisms distinct from RoCE Ethernet transport. RoCEv2 uses UDP/IP. Kubernetes CNI policy, adapter assignment, management-plane access and physical switch enforcement address different boundaries.

## Scope

Applies to governed clusters with InfiniBand or RoCE, including the actual switches, adapters, managed services, management routes and workload access mechanisms. Record protocol variant, expected tenant reachability and approved exceptions.

## Enforcement

- Primary Enforcement Point: Effective fabric and management controls, with independently verified adapter assignment and applicable Kubernetes policy.
- Implementation Surface: Verify relevant fabric configuration and approved administrative access. Check InfiniBand partition membership and enforcement or the specific RoCE Ethernet and routed controls. Verify actual workload and adapter placement and supported reachability observations. Distinguish ordinary CNI policy and host DMA protection.
- Owner Primary: Network Engineering
- Owner Supporting: GPU Infrastructure Engineering; ML Platform Engineering; Security Engineering
