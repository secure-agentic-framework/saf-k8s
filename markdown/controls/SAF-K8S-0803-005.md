# SAF-K8S-0803-005 - DPU and SmartNIC firmware cryptographic verification and Secure Boot integrity

- Domain: D08 - GPU, Accelerator, and Confidential Computing
- Knowledge Area: 8.3 - High-Performance Interconnect Security
- Maturity: Advanced
- Classification: ai-specific

## Statement

On governed DPU and SmartNIC models, require supported firmware integrity and device boot-chain controls for the approved operating mode. Verify actual device identity, effective boot policy, approved firmware and current evidence for the relevant boot stages.

## Objective

Restrict device operation to supported trusted firmware states and detect unsupported or unexplained changes.

## Rationale

A verified artifact, effective device Secure Boot, independent measurement and runtime firmware inventory have distinct evidentiary scopes. Signature verification can be part of the boot trust chain and is not necessarily a separate trust anchor. Host measurements do not by themselves establish the state of an offload device.

## Scope

Applies to governed programmable offload devices and supported firmware, boot stages, management paths and trust features. Identify vendor, device, platform configuration, authorized revision, required report binding and unsupported claims.

## Enforcement

- Primary Enforcement Point: Vendor-supported device root of trust and boot policy, independently bound measurements and approved firmware inventory.
- Implementation Surface: Verify configuration-specific vendor evidence of approved signers, effective policy and relevant boot components. Independently obtain current device-bound evidence and approved version state, check freshness and provenance, and investigate changes or unsupported observations.
- Owner Primary: Network Engineering
- Owner Supporting: GPU Infrastructure Engineering; Security Engineering; Platform Engineering
