# SAF-K8S-0203-015 - Cloud metadata endpoint restriction settings

- Domain: D02 - Node, Runtime, and OS Security
- Knowledge Area: 2.3 - Host OS and Kernel Hardening
- Maturity: Foundational
- Classification: baseline

## Statement

Apply supported endpoint, path and exposure restrictions for each governed provider metadata service. Define the endpoint and caller classes covered, approved node dependencies, and expected behavior for legacy versions, IP families and routed paths. Verify actual reachability.

## Objective

Constrain effective metadata exposure to approved service paths and callers while retaining required node behavior.

## Rationale

Endpoint disablement, retirement of a legacy route, a response hop limit, and Pod traffic filtering cover different paths. A restrictive setting alone does not establish node, Pod, managed identity or protocol coverage.

## Scope

Applies to governed cloud nodes and pools whose platform provides metadata services. Document product, supported endpoint and IP versions, relevant node and workload sources, provider defaults and customizations, exceptions and required services.

## Enforcement

- Primary Enforcement Point: Effective provider endpoint and routing settings and supported network controls at each relevant caller boundary.
- Implementation Surface: Inventory actual endpoint modes, applicable response hop limits, caller classes and retained dependencies. Verify denied and allowed harmless paths in authorized fixtures or deployments. Obtain provider and node evidence independently of application-level request guards.
- Owner Primary: Cloud Infrastructure
- Owner Supporting: Platform Engineering; Security Engineering
