# SAF-K8S-0704-020 - Node-level cloud identity restriction for managed Kubernetes workloads

- Domain: D07 - Storage, Multi-tenancy, and Resource Governance
- Knowledge Area: 7.4 - Cloud Provider Security Integration
- Maturity: Foundational
- Classification: baseline

## Statement

Limit each managed Kubernetes node identity to documented bootstrap, node and platform agent duties. Verify provider controls that restrict application access to node credentials. Grant application access through approved workload identities and govern necessary exceptions.

## Objective

Preserve needed node and platform functions while limiting shared node authority and verifying the identity used for application cloud operations.

## Rationale

Node IAM policy, credential endpoint reachability and workload identity authorization are separate protections. Their enforcement depends on provider, network mode and node or platform responsibilities. Verify retained permissions and approved exceptions independently.

## Scope

Applies to governed managed worker pools, node identities and associated provider grants, workload identities and alternate credential paths. Include required system components and explicitly approved exceptions.

## Enforcement

- Primary Enforcement Point: Effective provider node identity permissions and credential isolation, with separate workload identity authorization.
- Implementation Surface: Inventory node duties, platform dependencies and workload requirements. Scope active provider grants and trust, verify credential paths and network modes, and observe actual node and workload authorization and attribution with scoped approved probes.
- Owner Primary: Cloud Platform Engineering
- Owner Supporting: Platform Engineering; Security Engineering
