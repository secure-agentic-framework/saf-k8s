# SAF-K8S-0202-003 - Container runtime patching and version management

- Domain: D02 - Node, Runtime, and OS Security
- Knowledge Area: 2.2 - Container Runtime Security
- Maturity: Foundational
- Classification: baseline

## Statement

Inventory runtime versions by node pool against approved vendor support and Kubernetes compatibility sources. Define risk-based patch deadlines, their start events and exception authority. Apply applicable fixes within those deadlines and verify installed state. Validate workload compatibility and recovery on a representative canary before rolling out to production.

## Objective

Ensure that known container runtime vulnerabilities are remediated promptly and that runtime updates do not introduce compatibility regressions that could affect workload availability or security posture.

## Rationale

Vendor support, advisory applicability, effective installed state and the organization's remediation deadline are distinct facts. Validate updates against the Kubernetes version and required workload, network, storage and device functions before deployment. Retain the canary result and an approved recovery path.

## Scope

Applies to containerd, CRI-O, runc and applicable supplementary runtime components on governed nodes. For provider-operated runtimes, record applicable provider support and patch commitments and corroborate the installed build or remediation status for the affected pool. Record unavailable evidence and approved exceptions.

## Enforcement

- Primary Enforcement Point: Node image build pipeline, vulnerability scanning integration, and change management process for runtime version updates.
- Implementation Surface: Per-pool runtime and node image inventory, dated vendor support and Kubernetes compatibility sources, advisory applicability decisions, approved severity-based deadlines, exception and installed-patch evidence, and the documented canary and recovery procedure.
- Owner Primary: Platform Engineering
- Owner Supporting: Security Engineering; Vulnerability Management
