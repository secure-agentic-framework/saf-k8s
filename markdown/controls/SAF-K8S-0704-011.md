# SAF-K8S-0704-011 - Network-level blocking of cloud metadata endpoint access for pods

- Domain: D07 - Storage, Multi-tenancy, and Resource Governance
- Knowledge Area: 7.4 - Cloud Provider Security Integration
- Maturity: Foundational
- Classification: baseline

## Statement

Restrict workload network access to node metadata endpoints by default on each governed cloud platform. Approve and document narrowly scoped infrastructure exceptions. Verify denial and permitted paths using the deployed provider, CNI and node controls, and govern workload identity separately.

## Objective

Limit workload access to node-scoped metadata and authorize necessary workload access through independently scoped identities.

## Rationale

Provider metadata services, workload identity endpoints and network enforcement differ by platform and workload mode. Verified egress restrictions and node controls reduce access to node-scoped metadata. Workload identity, node role permissions and metadata service configuration provide separate protections.

## Scope

Applies to governed workloads where node metadata is exposed. Inventory application and infrastructure workload network modes, policy enforcement implementations, provider metadata and identity paths, and documented exceptions.

## Enforcement

- Primary Enforcement Point: Deployed provider, CNI and node egress controls with a separately enforced workload identity policy.
- Implementation Surface: Inventory provider-approved paths and enforcement for all applicable workload modes. Test ordinary workload denial, approved infrastructure access and authorized identity behavior with scoped probes and no retained credentials. Record justified exceptions, approval and expiry, and verify deployed policy, node permissions and workload identity independently.
- Owner Primary: Cloud Platform Engineering
- Owner Supporting: Platform Engineering; Security Engineering
