# SAF-K8S-0103-013 - Cloud controller-manager workload identity and credential rotation

- Domain: D01 - Control Plane and Cluster Hardening
- Knowledge Area: 1.3 - Controller-Manager, Scheduler, and Cloud Controller Security
- Maturity: Practitioner
- Classification: baseline

## Statement

Use a provider-supported managed or federated identity with bounded credentials for governed cloud controllers. Inventory effective credential sources and fallbacks. Require approved exceptions with bounded lifetime, automated renewal and retirement of superseded credentials.

## Objective

Limit controller credential exposure and preserve supported reconciliation through verified issuance, refresh and revocation.

## Rationale

Credential federation, provider issuance, refresh and effective permissions are distinct. Short-lived identity reduces exposure only when the running controller uses the intended source and consumes refreshed credentials. Provider-managed control planes can have tenant visibility limits.

## Scope

Applies to governed controller cloud credential paths, including provider-managed, self-managed and in-cluster operation where relevant. Identify audience and trust, issuer, credential chain, baseline lifetime, fallback, approved exceptions and evidence ownership.

## Enforcement

- Primary Enforcement Point: Resolved credential source and effective provider trust and issuance at the controller runtime, with verified refresh and retirement.
- Implementation Surface: Exercise expected issuance, wrong audience or unauthorized subject handling where supported, consumer refresh, superseded session revocation and provider audit evidence. Inventory static and alternate credentials, approved exceptions and associated lifetime limits separately from effective IAM.
- Owner Primary: Platform Engineering
- Owner Supporting: Cloud Platform Engineering; Security Engineering
