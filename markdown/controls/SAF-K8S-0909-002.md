# SAF-K8S-0909-002 - Embedding pipeline integrity

- Domain: D09 - AI Workload Security: Training, Serving, and Pipelines
- Knowledge Area: 9.9 - RAG Infrastructure Security
- Maturity: Practitioner
- Classification: ai-specific

## Statement

Before generating embeddings, verify the approved identity and integrity of the embedding model and associated runtime and validate governed inputs. Record and evaluate output consistency under the approved reproducibility criteria.

## Objective

Verify that governed indexing uses approved model and document bytes and produces auditable results within verified tolerances.

## Rationale

A substituted model or unverified input can change indexed results. A digest establishes integrity against an approved expected value. Authenticate the model provenance through a trusted signer or equivalent authority, and verify consistency in the supported environment.

## Scope

Applies to Kubernetes embedding workloads for retrieval indexes, including model and runtime identity, input validation and reproducibility evidence. Document the supported formats, numerical tolerances and evaluation conditions.

## Enforcement

- Primary Enforcement Point: Model verification at the workload or release boundary, document validation before embedding, and controlled evaluation of emitted vectors.
- Implementation Surface: Verify the approved model digest and trusted signature, pin the preprocessing and runtime versions, use validated parsers and format and size limits, and observe known outputs under the supported environments. Record expected variation, model revision and input decisions.
- Owner Primary: ML Platform Engineering
- Owner Supporting: Security Engineering; Data Engineering
