# SAF-K8S-0504-006 - SPIFFE/SPIRE workload identity issuance and lifecycle management

- Domain: D05 - Network Security and Communication
- Knowledge Area: 5.4 - Zero Trust Architecture and Service Mesh
- Maturity: Advanced
- Classification: baseline

## Statement

Issue SPIFFE Verifiable Identity Documents to eligible workloads using SPIRE or an equivalent provider. Verify registration and attestation, then verify automatic renewal of short-lived documents for the intended stable SPIFFE ID.

## Objective

Provide cryptographically verifiable workload identities that enable identity-based access control independent of network location.

## Rationale

Without cryptographic workload identity issuance and rotation, services fall back to network-based trust that can be spoofed or bypassed. Separating identity lifecycle management from federation governance makes local workload identity controls independently auditable.

## Scope

Applies to production Kubernetes workloads that use SPIFFE identity. Verify server and agent availability, trust-domain governance, and the service mesh or application integration where applicable. Evaluate cross-trust-domain federation under SAF-K8S-0504-007.

## Enforcement

- Primary Enforcement Point: SPIFFE/SPIRE workload identity issuance and attestation controls.
- Implementation Surface: Configure workload registration, node and workload attestation, SVID lifetime and automatic renewal. Verify the SPIFFE URI, the relevant trust bundle, permitted and denied issuance, and consumer behavior during renewal. Retain evidence for the actual server, agent and relying application paths.
- Owner Primary: Security Engineering
- Owner Supporting: Platform Engineering; Network Engineering
