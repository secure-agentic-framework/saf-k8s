# SAF-K8S-0303-006 - MAC profile iterative refinement cycle

- Domain: D03 - Workload and Pod Security
- Knowledge Area: 3.3 - Mandatory Access Controls
- Maturity: Practitioner
- Classification: baseline

## Statement

Refine governed workload profiles whenever relevant workload, dependency or runtime changes alter expected operations. Promote an exact revision only after representative use cases, required policy events, final enforcing decisions and recovery are verified.

## Objective

Keep the profile aligned with approved workload behavior across exercised operational paths and preserve restrictions on operations outside that approval.

## Rationale

Repeated clean observation cycles can miss the same unexercised path or uncollected event. A local cycle threshold is a change-management criterion. Verified path coverage, accurate event collection and enforcing tests determine the supported evidence.

## Scope

Applies to governed workload profiles and material workload, runtime, hardware or policy changes. Define each applicable operating and recovery path and supported observation mode.

## Enforcement

- Primary Enforcement Point: Versioned profile review, scoped workload and telemetry checks, final enforcement verification, promotion approval and rollback.
- Implementation Surface: Bind exact profile revisions to the workload and supported platform. Use an explicit path inventory, calibrate event collection, distinguish legitimate from incidental or excluded operations, test selective changes under enforcement and exercise recovery. Reassess the affected paths after material changes.
- Owner Primary: Security Engineering
- Owner Supporting: Platform Engineering; Application Development teams
