# SAF-K8S-1004-001 - ML threat taxonomy per CTA-2114 mapped to Kubernetes

- Domain: D10 - Observability, Incident Response, and Governance
- Knowledge Area: 10.4 - AI and Supply Chain Threat Taxonomy
- Maturity: Advanced
- Classification: ai-specific

## Statement

Organizations must verify CTA-2114's normative ML threat classes and definitions using an authorized copy, and, where applicable to the AI systems in scope, adopt and apply the verified CTA-2114 taxonomy as the formal classification framework for AI-specific threats. The class labels and groupings currently listed in this control (Data Poisoning, Model Poisoning, Targeted Poisoning, Label Modification, Model Disclosure, Data Disclosure, Evasion, Oracle Attacks (extraction, inversion, membership inference), and Denial of Service via computational complexity) are provisional SAF-K8S examples until checked against that copy; they are not asserted as CTA-2114 categories or definitions. Organizations must map each applicable verified CTA-2114 threat class to Kubernetes infrastructure attack surfaces, control points, and detection mechanisms.

## Objective

Establish a consistent AI threat-classification and Kubernetes mapping using applicable CTA-2114 classes after their names, definitions, and coverage have been verified against authorized normative text, enabling risk communication, detection development, and control mapping across Kubernetes AI infrastructure.

## Rationale

AI threats described inconsistently can leave gaps between threat modeling, detection, and control planning. A verified and consistently applied classification mapped to Kubernetes attack surfaces can support those activities. The class labels and groupings currently listed in this control are provisional SAF-K8S examples; the publicly available CTA listing confirms CTA-2114’s title, publication date, and broad ML cybersecurity and privacy scope, but does not expose the normative classes or definitions. Before asserting CTA alignment or completeness, verify the authorized text and reconcile the class set and boundaries. NIST AI 100-2e2025 is a separate comparator and does not establish CTA-2114 content.

## Scope

Applies to all organizations operating AI workloads on Kubernetes. Where CTA-2114 is applicable, the taxonomy mapping must cover all threat classes verified against an authorized current copy and must be referenced in threat modeling, detection rule development, and incident classification. The class labels and groupings presently listed in this record are provisional SAF-K8S examples pending that verification; they do not establish CTA-2114 terminology or complete coverage. The mapping must be reviewed when CTA-2114 is updated or when new AI workload types are introduced.

## Enforcement

- Primary Enforcement Point: Threat modeling documentation standards, detection rule taxonomy tagging, and incident classification schema.
- Implementation Surface: Authorized CTA-2114 source and version review; documented verification and adoption of applicable normative threat classes; reconciliation of the provisional SAF-K8S example labels and groupings currently listed in this record (Data Poisoning, Model Poisoning, Targeted Poisoning, Label Modification, Model Disclosure, Data Disclosure, Evasion, Oracle Attacks (extraction, inversion, membership inference), and Denial of Service via computational complexity); verified threat-class-to-Kubernetes attack-surface, control-point, and detection mappings; threat-modeling documentation standards; detection-rule taxonomy tagging in SIEM; and incident-classification schema aligned with the verified CTA-2114 classes.
- Owner Primary: Security Architecture
- Owner Supporting: AI/ML Engineering; Detection Engineering; GRC/Compliance
