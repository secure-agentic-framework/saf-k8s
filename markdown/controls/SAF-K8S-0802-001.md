# SAF-K8S-0802-001 - GPU driver lifecycle and vulnerability management

- Domain: D08 - GPU, Accelerator, and Confidential Computing
- Knowledge Area: 8.2 - GPU Driver, Library, and Toolkit Security
- Maturity: Practitioner
- Classification: ai-specific

## Statement

Inventory effective accelerator driver versions and owners across node pools, review applicable public advisories, validate workload compatibility, and remediate or contain affected versions within approved deadlines. Verify controlled rollout, live component state and recovery.

## Objective

Reduce exposure to applicable disclosed driver vulnerabilities while maintaining supported runtime compatibility and operational recovery.

## Rationale

Driver changes and reported defects have mode- and version-specific effects. Selected kernel, operating system, device, runtime and workload combinations need separately verified support. Upgrade behavior and recovery depend on whether the driver is host-installed, provider-managed or operator-managed.

## Scope

Applies to governed accelerator nodes including host-installed, vendor operator-managed, virtualized and provider-managed drivers. Record operational ownership, effective versions, applicable advisories, exceptions and maintenance evidence.

## Enforcement

- Primary Enforcement Point: Effective driver inventory, public advisory disposition, compatibility review and supported controlled upgrade and recovery.
- Implementation Surface: Record kernel and user-space versions, provider ownership, applicable security findings, release provenance and approved disposition. Use the supported upgrade path for the actual installation type. Validate workload health and effective versions following rollout and exercise recovery to an approved release when applicable.
- Owner Primary: GPU Infrastructure Engineering
- Owner Supporting: ML Platform Engineering; Vulnerability Management; Security Engineering
