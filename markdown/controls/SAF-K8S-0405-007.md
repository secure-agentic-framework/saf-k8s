# SAF-K8S-0405-007 - Authentication endpoint availability and DoS protection

- Domain: D04 - Identity, Access, and Secrets Management
- Knowledge Area: 4.5 - Identity Abuse Detection and Mitigation
- Maturity: Practitioner
- Classification: baseline

## Statement

Define availability requirements, overload safeguards and measurements for the actual API authentication and identity-provider paths. Verify effective API-server configuration and APF classification, and separately verify provider protection and response targets.

## Objective

Preserve authorized access within defined availability objectives and distinguish request classification, authentication errors and authorization outcomes.

## Rationale

API-server in-flight flags set concurrency behavior. APF classifies and manages eligible API requests. The API authenticator, external identity providers and authorization decisions have distinct failure modes and protection controls.

## Scope

Applies to the authorized Kubernetes API path and independently identified issuer, discovery, webhook and managed identity dependencies. Document provider boundaries, measurement scope and unsupported behavior.

## Enforcement

- Primary Enforcement Point: Effective, observed request-path controls and monitored health at each actual service and dependency.
- Implementation Surface: Inventory authentication paths and dependencies. Validate real APF classification under ordinary traffic, distinct status and health signals, configured provider-side protections, recovery and approved monitoring objectives. Treat capacity and failure behavior as separately observed deployment evidence.
- Owner Primary: Platform Engineering
- Owner Supporting: Identity and Access Management; Security Engineering
