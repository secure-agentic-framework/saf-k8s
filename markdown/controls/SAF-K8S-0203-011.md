# SAF-K8S-0203-011 - Immutable node root filesystem enforcement

- Domain: D02 - Node, Runtime, and OS Security
- Knowledge Area: 2.3 - Host OS and Kernel Hardening
- Maturity: Foundational
- Classification: baseline

## Statement

Use a supported immutable or effectively read-only OS root for applicable governed nodes. Define the protected root scope, explicitly permitted writable state, approved update and recovery paths, and separate integrity evidence.

## Objective

Constrain unauthorized root filesystem changes and make writable state and authorized version transitions observable.

## Rationale

Read-only root and authenticated image integrity provide different properties. Writable storage, configuration APIs and process state can persist independently across reboot or replacement. Define the effective trust and persistence boundaries.

## Scope

Applies to governed node OS deployments with supported immutability. Inventory applicable root enforcement, allowed writable and persistent paths, provisioning owner, update and rollback model, provider responsibility and exceptions.

## Enforcement

- Primary Enforcement Point: Effective root media or mount policy, separately allowed state, supported image lifecycle and integrity evidence as applicable.
- Implementation Surface: Verify root write rejection on a harmless owned path, permitted managed state, and observed persistence across an approved image transition. Validate image integrity, drift monitoring and provider ownership separately.
- Owner Primary: Platform Engineering
- Owner Supporting: OS/Infrastructure; Security Engineering
