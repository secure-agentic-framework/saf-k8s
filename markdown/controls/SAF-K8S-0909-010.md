# SAF-K8S-0909-010 - Vector database encryption in transit and at rest

- Domain: D09 - AI Workload Security: Training, Serving, and Pipelines
- Knowledge Area: 9.9 - RAG Infrastructure Security
- Maturity: Practitioner
- Classification: ai-specific

## Statement

Encrypt governed vector database transport and persisted vector and metadata storage, including applicable replicas, snapshots and backups. Verify the effective client and storage boundaries and approved key management.

## Objective

Protect vector content and metadata on the governed network and storage paths and verify authorized recovery.

## Rationale

TLS can authenticate and encrypt the selected connections when endpoint identity is verified. Storage protections depend on the actual provider, covered volumes or exports and separate key custody. Successful persistence or restart alone cannot establish encryption.

## Scope

Applies to governed network listeners and internal paths, active storage, retained snapshots and backups. Use the applicability and evidence required by the deployed engine and provider.

## Enforcement

- Primary Enforcement Point: The verified transport endpoint and the active and retained storage layers that provide encryption.
- Implementation Surface: Check trusted certificate chains and server identity, expected plaintext and untrusted denials, enabled encryption on the attached storage and retained copies, key custody and recovery, and positive observations using authorized requests and recovery workflows.
- Owner Primary: ML Platform Engineering
- Owner Supporting: Security Engineering; Infrastructure Engineering
