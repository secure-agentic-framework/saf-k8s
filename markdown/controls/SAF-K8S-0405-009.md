# SAF-K8S-0405-009 - API impersonation RBAC restriction

- Domain: D04 - Identity, Access, and Secrets Management
- Knowledge Area: 4.5 - Identity Abuse Detection and Mitigation
- Maturity: Practitioner
- Classification: baseline

## Statement

Inventory effective impersonation authorization and permit it only for approved callers and exact identity values. Use the appropriate namespaced or cluster-scoped grants and independently govern the delegated identity's permissions. Verify ordinary and any supported constrained impersonation mechanisms.

## Objective

Allow only approved identity delegation and bound the resulting access to the intended operation and scope.

## Rationale

An ordinary impersonation name grant limits the identity values that may be supplied. Subsequent authorization uses the resolved delegated identity. Assertion or token integrity is an independent authentication responsibility.

## Scope

Applies to governed Kubernetes impersonation grants for users, groups, ServiceAccounts, extra values and UIDs. Identify actual feature availability, namespace scope, authorized caller and approved delegated access.

## Enforcement

- Primary Enforcement Point: Effective API authorization for exact impersonation identity values and the resulting governed operation.
- Implementation Surface: Inventory approval, role and effective authorization. Verify allowed and unlisted identity values, namespace scope, a harmless authorized operation and verified grant removal. Review delegated identity permissions and constrained impersonation where supported.
- Owner Primary: Security Engineering
- Owner Supporting: Platform Engineering; Security Operations
