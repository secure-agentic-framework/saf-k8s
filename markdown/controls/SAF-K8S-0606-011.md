# SAF-K8S-0606-011 - CI build-time security gate enforcement

- Domain: D06 - Supply Chain, Images, and Admission Control
- Knowledge Area: 6.6 - CI/CD and GitOps Pipeline Security
- Maturity: Practitioner
- Classification: baseline

## Statement

Enforce applicable security checks before promoting governed Kubernetes artifacts. Tie decisions to the exact artifact digest, source revision, test revision and policy revision. Block failed, missing and skipped required checks unless a separately governed exception applies. Manage source-control push protection at the repository boundary.

## Objective

Give required build checks a verifiable effect on whether the exact artifact proceeds to release.

## Rationale

Source-control protections, CI evaluation and artifact promotion protect different stages. Binding results to the exact artifact and relevant revisions prevents a passing decision for one candidate from authorizing another candidate.

## Scope

For governed CI and artifact classes, document applicable source analysis, component analysis, credential detection, dependency change review, artifact checks and dynamic testing as appropriate to deployment stage, risk and approved policy.

## Enforcement

- Primary Enforcement Point: Required CI checks and release promotion policy, with source-control protections enforced at the repository boundary.
- Implementation Surface: Configure required checks from approved evidence producers, reject absent or unsuccessful applicable checks and verify digest and revision bindings at promotion. Record source-control protections and exceptions separately. Govern exception approvers, allowed reasons, artifact and check scope, expiry, and auditing. Require separate verification of the evidence writer and release permissions.
- Owner Primary: DevSecOps / Release Engineering
- Owner Supporting: Security Engineering; Development Teams
