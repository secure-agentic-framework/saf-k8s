# SAF-K8S-0905-006 - Model artifact lifecycle management

- Domain: D09 - AI Workload Security: Training, Serving, and Pipelines
- Knowledge Area: 9.5 - AI Supply Chain and Model Lifecycle
- Maturity: Advanced
- Classification: ai-specific

## Statement

Organizations must implement model deprecation, archival, and secure deletion procedures for retired model versions and must propagate data correction and deletion notices to all derived model artifacts using ML-BOM lineage tracking.

## Objective

Manage model version retirement, archival and verified disposition. Trace data correction and deletion notices to affected releases and document approved action.

## Rationale

Retired artifacts can remain reachable through registries, replicas and retained copies. Lineage identifies potentially affected versions for review. Evaluate any applicable data protection obligations for the actual data and model before deciding and verifying the resulting action.

## Scope

Applies to all model artifacts across their lifecycle on Kubernetes, from initial registration through deprecation and deletion. Covers model version archival, secure deletion, and data correction propagation. Excludes environment separation covered by SAF-K8S-0905-012.

## Enforcement

- Primary Enforcement Point: Model registry lifecycle policies and data deletion propagation workflows.
- Implementation Surface: Record owned model-version identities, governed deprecation and archival states, verified archive integrity and authorized disposition with evidence for actual copies, retention and recovery. Trace correction and deletion notices through reconciled ML-BOM lineage, assign review and follow through to the approved action. Independently verify any applicable erasure mechanism and result.
- Owner Primary: ML Platform Engineering
- Owner Supporting: Data Engineering; Compliance
