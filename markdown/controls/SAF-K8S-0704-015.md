# SAF-K8S-0704-015 - Effective external identity and Kubernetes API entitlement mapping

- Domain: D07 - Storage, Multi-tenancy, and Resource Governance
- Knowledge Area: 7.4 - Cloud Provider Security Integration
- Maturity: Practitioner
- Classification: baseline

## Statement

Maintain a reviewed inventory linking every in-scope external principal to the Kubernetes API authentication path, resolved subject attributes, effective authorizers and permitted resource actions. Trace grants through Kubernetes RBAC, provider authorization policies or other configured authorizers as applicable.

## Objective

Make effective Kubernetes API access attributable to the source identity, resolved attributes, authorizer and scoped grant.

## Rationale

Authentication supplies the request identity. Kubernetes RBAC, provider access policies or other active authorizers can independently affect permissions. A traceable inventory and effective authorization checks support access design, review and incident investigation.

## Scope

Applies to managed clusters and self-managed clusters accepting external identities. Cover human administrators, automation and workload principals where applicable, group resolution, all active authorizers and approved exceptions.

## Enforcement

- Primary Enforcement Point: External identity configuration, cluster authentication and authorization, and evidence-backed access inventory.
- Implementation Surface: Record the effective cluster mode, identity source, resolved subjects, named authorizers and policy or binding scopes. Reconcile inventory entries with actual provider settings and Kubernetes objects. Verify and retain representative permitted and denied requests for each applicable path.
- Owner Primary: Cloud Platform Engineering
- Owner Supporting: Security Engineering; Platform Engineering
