# SAF-K8S-0405-003 Kubeconfig policy and issued authorization

Run by ID on fresh Kind. An inert synthetic file exercises the fixture
configuration checks. An approved owner-only profile uses a server-issued
short-lived credential, scoped access and the actual API endpoint. After
the bound fixture object is deleted, the unchanged profile stops working.

The test uses only owned temporary kubeconfig paths and keeps its private
credential out of retained material. Assess storage encryption, actual
credential plugins, offboarding, and shared workstation policies separately.

- [Kubernetes service account administration](https://v1-36.docs.kubernetes.io/docs/reference/access-authn-authz/service-accounts-admin/)
