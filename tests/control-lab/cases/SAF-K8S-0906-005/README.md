# SAF-K8S-0906-005 annotation approval

Run `python3 lab.py test SAF-K8S-0906-005` from the control-lab directory.

Each fixture service account can update only its named synthetic review
records. A separate curator owns the correction. The processor receives the
sealed review bundle and writes an unchecked and a governed release. A
separate reader verifies the stored labels and dataset version. The
governed result holds a clerical mismatch, a prior dataset version and a
repeated reviewer, while retaining two appropriately adjudicated records.

Agreement and label frequencies can guide review. Production evidence must
establish actual annotator identity, release and review custody, sampling
validity, and monitoring performance.
