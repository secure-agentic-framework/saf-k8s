# SAF-K8S-0405-004 Role-based training provisioning

Run by ID on fresh Kind. A fixture training record governs an API
RoleBinding for a synthetic GPU quota reader. The gate denies a
pending or wrong-subject approval, allows the exact current approval
and denies new grants after a controlled review makes it overdue.
The case also shows that existing access needs a separate action.

The record is fictional. Verify real curriculum, participant
completion and demonstrated learning with the responsible organization.
