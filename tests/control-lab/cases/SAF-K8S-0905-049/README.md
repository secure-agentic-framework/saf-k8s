# SAF-K8S-0905-049

Run `python3 lab.py test SAF-K8S-0905-049`. Two disposable Zot v2.1.23
instances compare the same owned fixture operations with repository update
and delete permissions enabled or denied. The scoped read/create policy
preserves the original tag digest while admitting a distinct new tag.
The client independently hashes manifest bytes retrieved over the OCI API.
Zot's native audit file records successful writes. The case verifies both denied mutations in the HTTP access stream. Deployed registry protection and audit forwarding require separate evidence.
