# SAF-K8S-0908-008 Response shaping and utility

Run by ID on fresh Kind. Two separate services receive the same fixed
synthetic inputs. The protected service serves only its shaped
prediction schema. Largest-remainder allocation coarsens the vector
to tenths while preserving normalization. The test measures top-one
agreement and mean absolute confidence error against a declared bound.

Verify actual disclosure risk, model utility and any formal privacy
guarantee at deployment. The case reuses the pinned runtime in
SAF-K8S-0908-001.
