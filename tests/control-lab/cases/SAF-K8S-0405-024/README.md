# SAF-K8S-0405-024 Automatic emergency access retirement

Run by ID on fresh Kind. The record alone leaves the temporary grant
effective. The scoped in-cluster Job reads the approved deadline and
withdraws only that named binding. The same real fixture credential
receives a denial afterward and the independent approved reader still
works. The case imports temporary identity helpers from SAF-K8S-0405-020.

This demonstrates automatic authorization withdrawal. Verify actual
credential expiry, bound-object invalidation, relying-party behavior
and external issuer controls where the deployed procedure uses them.
