# SAF-K8S-0804-006 Authenticated artifact context and recipient binding

Requires a local Go toolchain, kubectl and Kind. The Go standard library encrypts a public fixture marker under an in-memory key. Kubernetes stores only ciphertext and a synthetic context in an immutable ConfigMap. Four checks cover the unbound baseline, policy and measurement mismatch plus ciphertext tampering, approved API round trip, and independent artifact identity, fixed plaintext digest, and synthetic recipient mismatches. Each mismatch changes one context field at a time. Before reporting successful opens or denials, the fixture requires the exact immutable ConfigMap name/namespace, context bytes, artifact metadata, expected ciphertext bytes, and expected fixed plaintext digest; malformed or altered metadata is a fixture error rather than a counted denial.

Run via the standard control lab entry point. The added context fields are synthetic application-level AES-GCM associated data. Hardware-backed sealing, external key release, recipient authorization, platform measurement, freshness, migration, recovery, and provider assurance require deployment evidence. This fixture does not persist the key or use a real platform measurement.
