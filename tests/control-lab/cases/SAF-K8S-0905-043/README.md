# SAF-K8S-0905-043

Run `python3 lab.py test SAF-K8S-0905-043`. A pinned OCI registry stores two
inert model versions. The test associates a synthetic ML-BOM record with
one exact manifest digest and independently checks discovery, subject and
payload bytes. After the registry Pod is replaced and its claim is reused,
the same attachment is retrieved again. Deployment retention, replication,
promotion integrations and ML-BOM generation require their own evidence.
