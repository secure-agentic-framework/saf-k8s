# SAF-K8S-0906-004 pre-training quality gate

Run `python3 lab.py test SAF-K8S-0906-004` from the control-lab directory.

All records are simple invented measurements. A Kind processor compares them
to an immutable snapshot. A read-only reader verifies the stored outputs from
the unchecked and governed branches. Independent schema/bounds, mean drift
and outlier checks leave only the approved digest in the governed release.

The fixed thresholds illustrate a quality check. Deployment evidence must
establish representative sampling, useful calibration, operational handling,
and the separate evidence needed to attribute data integrity events.
