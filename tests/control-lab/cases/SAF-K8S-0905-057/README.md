# SAF-K8S-0905-057 — Document model trust decisions before eligibility

Run the case by ID from the framework checkout.

    python3 tests/control-lab/lab.py test SAF-K8S-0905-057 --docker-context desktop-linux

A restricted Kubernetes Job evaluates fictional maintenance, publisher documentation and community evidence from an immutable dossier. Both inert candidates carry equivalent fixture provenance handoffs. The Job stores the approval and rejection with their reasons and reviewer details. A native admission policy checks the approved digest for labeled Pod requests. The same rejected request passed before activation, and the approved request still passes after activation.

The case treats provenance status and human review evidence as synthetic inputs. Verify their production authenticity, ongoing review, authorized enrollment and policy coverage separately.
