# SAF-K8S-1005-014

This exercise applies a business priority rule to three mock Kubernetes ConfigMaps. It
rejects a training-first plan that skips a prerequisite and leaves an unlinked review
finding open. The approved plan restores the exact prerequisite, inference fixture and
training fixture in order. Independent API reads verify the successor playbook reference,
restoration order, fresh object identities and matching data.

The exercise demonstrates reviewed priorities and a traceable preparedness improvement
with synthetic records. Real business impact decisions, backup validation, recovery time,
incident response and recurring preparedness work need organization-specific evidence.
