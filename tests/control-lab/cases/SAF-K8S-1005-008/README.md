# SAF-K8S-1005-008

A tokenless in-cluster mock responder checks routing for four synthetic exercise scenarios.
Disabled playbooks, a missing owner and a mismatched resource produce negative outcomes.
The enabled configuration matches the known alert name, source, evidence and resource to
the exact owner and planned action. The runner exercises and restores only the labeled
fixture resources. The GPU scenario exercises routing and verifies that its object remains
unchanged. A healthy observation takes no action.

The model artifact is a text fixture. The digest establishes byte integrity only. NVIDIA
documents GPU utilization and other telemetry fields, which can inform a separate operational
review. The GPU receipt exercises a fictional escalation and supplies no GPU detection evidence.
Actual training and inference containment, drift detection, attribution, deployed response
coverage, and the annual exercise schedule remain separate work.
