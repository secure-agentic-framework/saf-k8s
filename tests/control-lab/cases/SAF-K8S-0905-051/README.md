# SAF-K8S-0905-051

Run `python3 lab.py test SAF-K8S-0905-051` from the lab runner directory. The
test compares two disposable Kind clusters. An ordinary scoped ServiceAccount
persists the same fixed synthetic approval in both. The enabled audit profile
records the authenticated actor, decision, server time, and the requested and
stored digest. The digest resolves to matching immutable fixture bytes.

The scoped policy captures only the case reviewer's named approval patch.
Human identity, deployed promotion integration, external audit delivery,
protected retention, and review procedures require deployment evidence.

[Kubernetes v1.36 audit documentation](https://v1-36.docs.kubernetes.io/docs/tasks/debug/debug-cluster/audit/)
